# SubD Revolve

Xoay profile thành SubD.

- **Mã lệnh:** `ClayooCreationRevolve`
- **Vị trí:** menu Clayoo, ô số 31
- **Icon:** `Resources/icons/subd-minimal/ClayooCreationRevolve.svg`
- **Gọi bằng dòng lệnh:** `ClayooCreationRevolve`, `ClayooRevolve`
- **Cách chạy:** từng bước trên dòng lệnh, kèm bảng BUILDERS; Enter để tạo, Esc để huỷ

## Cách dùng

1. Chọn profile.
2. Bấm hai điểm trục.

## Tuỳ chọn (lệnh phụ)


| Dòng lệnh | Ý nghĩa | Mặc định | Khoảng |
|---|---|---|---|
| `Levels=` | Mức làm mịn khi tạo (0 = lồng) | 0 | 0 … 4 |
| `Sides=` | Số cạnh vòng | 8 | 3 … 64 |
| `Points=` | Số điểm ngang | 8 | 2 … 200 |
