# Select Ring

Chọn vòng mặt cắt ngang cạnh bấm.

- **Mã lệnh:** `ClayooSelectionSelectRing`
- **Vị trí:** menu Clayoo, ô số 42
- **Icon:** `Resources/icons/subd-minimal/ClayooSelectionSelectRing.svg`
- **Gọi bằng dòng lệnh:** `ClayooSelectionSelectRing`, `ClayooSelectRing`
- **Cách chạy:** từng bước trên dòng lệnh; Enter để tạo, Esc để huỷ

## Cách dùng

1. Chọn vật SubD (lồng).
2. Bấm các cạnh, Enter.
