# Project to Plane

Ép các mặt đang chọn (hoặc tất cả) lên mặt phẳng SubD / CPlane.

- **Mã lệnh:** `ClayooEditProjectToPlane`
- **Vị trí:** menu Clayoo, ô số 16
- **Icon:** `Resources/icons/subd-minimal/ClayooEditProjectToPlane.svg`
- **Gọi bằng dòng lệnh:** `ClayooEditProjectToPlane`, `ClayooFlatten`
- **Cách chạy:** từng bước trên dòng lệnh; Enter để tạo, Esc để huỷ

## Cách dùng

1. Chọn vật SubD (lồng).
2. Enter.
