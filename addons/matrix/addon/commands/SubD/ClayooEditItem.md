# Edit Item

Dời / co / xoay các mặt đang chọn (hoặc cả vật).

- **Mã lệnh:** `ClayooEditItem`
- **Vị trí:** menu Clayoo, ô số 1
- **Icon:** `Resources/icons/subd-minimal/ClayooEditItem.svg`
- **Gọi bằng dòng lệnh:** `ClayooEditItem`, `ClayooItem`
- **Cách chạy:** từng bước trên dòng lệnh; Enter để tạo, Esc để huỷ

## Cách dùng

1. Chọn vật SubD (lồng).
2. Mode=Move/Scale/Rotate.
3. Bấm điểm gốc và điểm đích.

## Tuỳ chọn (lệnh phụ)

- Mode.
