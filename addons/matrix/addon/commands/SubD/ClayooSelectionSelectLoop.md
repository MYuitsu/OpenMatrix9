# Select Loop

Chọn vòng mặt chạy dọc cạnh bấm.

- **Mã lệnh:** `ClayooSelectionSelectLoop`
- **Vị trí:** menu Clayoo, ô số 43
- **Icon:** `Resources/icons/subd-minimal/ClayooSelectionSelectLoop.svg`
- **Gọi bằng dòng lệnh:** `ClayooSelectionSelectLoop`, `ClayooSelectLoop`
- **Cách chạy:** từng bước trên dòng lệnh; Enter để tạo, Esc để huỷ

## Cách dùng

1. Chọn vật SubD (lồng).
2. Bấm các cạnh, Enter.
