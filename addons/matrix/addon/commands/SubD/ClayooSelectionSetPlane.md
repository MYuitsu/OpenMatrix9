# Set SubD Plane

Đặt mặt phẳng SubD theo mặt bấm (dùng cho Project, Symmetry).

- **Mã lệnh:** `ClayooSelectionSetPlane`
- **Vị trí:** menu Clayoo, ô số 56
- **Icon:** `Resources/icons/subd-minimal/ClayooSelectionSetPlane.svg`
- **Gọi bằng dòng lệnh:** `ClayooSelectionSetPlane`, `ClayooSetPlane`
- **Cách chạy:** từng bước trên dòng lệnh; Enter để tạo, Esc để huỷ

## Cách dùng

1. Chọn vật SubD (lồng).
2. Bấm mặt.
