# Prong on Surface

Bấm lên mặt để đặt từng chấu theo pháp tuyến mặt.

- **Mã lệnh:** `BuilderProngOnSurface`
- **Vị trí:** menu Settings, ô số 8
- **Icon:** `Resources/icons/settings-minimal/BuilderProngOnSurface.svg`
- **Gọi bằng dòng lệnh:** `BuilderProngOnSurface`, `ProngOnSurface`
- **Cách chạy:** từng bước trên dòng lệnh, kèm bảng BUILDERS; Enter để tạo, Esc để huỷ

## Cách dùng

1. Chọn mặt.
2. Bấm các điểm.
3. Enter.

## Tuỳ chọn (lệnh phụ)

- Copy: đặt liên tục.

| Dòng lệnh | Ý nghĩa | Mặc định | Khoảng |
|---|---|---|---|
| `Size=` | Đường kính chấu | 0.6 | 0.1 … 5 |
| `Height=` | Cao trên mặt | 1 | 0.1 … 10 |
| `Drop=` | Sâu dưới mặt | 0.8 | 0 … 10 |
| `Taper=` | Vát | 0 | -50 … 100 |
| `Fillet=` | Bo đầu | 100 | 0 … 100 |
| `Rotate=` | Nghiêng | 0 | -60 … 60 |
| `VerticalOffset=` | Lệch theo pháp tuyến | 0 | -5 … 5 |
| `Copy=` | Đặt liên tục | Yes |  |
