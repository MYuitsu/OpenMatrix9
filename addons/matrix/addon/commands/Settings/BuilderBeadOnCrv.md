# Bead on Curve

Rải hạt tròn (milgrain) đều theo đường cong.

- **Mã lệnh:** `BuilderBeadOnCrv`
- **Vị trí:** menu Settings, ô số 11
- **Icon:** `Resources/icons/settings-minimal/BuilderBeadOnCrv.svg`
- **Gọi bằng dòng lệnh:** `BuilderBeadOnCrv`, `gvBeadOnCrv`, `BeadOnCurve`, `Milgrain`
- **Cách chạy:** từng bước trên dòng lệnh, kèm bảng BUILDERS; Enter để tạo, Esc để huỷ

## Cách dùng

1. Chọn đường cong.
2. Chọn Bead on Curve, chỉnh Size, Spacing, Start, End, ZOffset.
3. Enter để đặt hạt.

## Tuỳ chọn (lệnh phụ)

- Size: đường kính hạt.
- Spacing: khe giữa hạt.
- Start / End: đoạn đường cong dùng (%).
- ZOffset: nâng/hạ hạt, % cỡ hạt.

| Dòng lệnh | Ý nghĩa | Mặc định | Khoảng |
|---|---|---|---|
| `Size=` | Đường kính hạt | 0.6 | 0.05 … 5 |
| `Spacing=` | Khe giữa hạt | 0.05 | 0 … 3 |
| `Start=` | Bắt đầu | 0 | 0 … 100 |
| `End=` | Kết thúc | 100 | 0 … 100 |
| `ZOffset=` | Nâng/hạ (% hạt) | 0 | -100 … 100 |
