# Pavé Sphere

Tạo quả cầu phủ pavé đều.

- **Mã lệnh:** `BuilderPaveSphere`
- **Vị trí:** menu Gems, ô số 33
- **Icon:** `Resources/icons/gems-minimal/BuilderPaveSphere.svg`
- **Gọi bằng dòng lệnh:** `BuilderPaveSphere`, `PaveSphere`
- **Cách chạy:** từng bước trên dòng lệnh, kèm bảng BUILDERS; Enter để tạo, Esc để huỷ

## Cách dùng

1. Chỉnh bán kính, kích thước, khoảng cách.
2. Bấm tâm cầu.

## Tuỳ chọn (lệnh phụ)


| Dòng lệnh | Ý nghĩa | Mặc định | Khoảng |
|---|---|---|---|
| `Radius=` | Bán kính cầu | 5 | 1 … 50 |
| `Size=` | Kích thước đá | 1.2 | 0.3 … 10 |
| `Spacing=` | Khe giữa đá | 0.15 | 0 … 3 |
| `Sphere=` | Tạo cả quả cầu | Yes |  |
| `Material=` | Chất liệu | diamond | diamond, moissanite, cz, ruby, sapphire, emerald, amethyst, topaz, garnet, aquamarine, peridot, tanzanite |
