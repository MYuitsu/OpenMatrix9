# Gem on Surface

Bấm lên mặt để đặt từng viên đá, đá xoay theo pháp tuyến mặt.

- **Mã lệnh:** `BuilderGemOnSurface`
- **Vị trí:** menu Gems, ô số 11
- **Icon:** `Resources/icons/gems-minimal/BuilderGemOnSurface.svg`
- **Gọi bằng dòng lệnh:** `BuilderGemOnSurface`, `GemOnSurface`
- **Cách chạy:** từng bước trên dòng lệnh, kèm bảng BUILDERS; Enter để tạo, Esc để huỷ

## Cách dùng

1. Chọn mặt.
2. Bấm các điểm trên mặt (xem trước khi rê chuột).
3. Enter để kết thúc.

## Tuỳ chọn (lệnh phụ)

- VerticalOffset, Angle, Flip, Spacing (vòng hướng dẫn), Copy.

| Dòng lệnh | Ý nghĩa | Mặc định | Khoảng |
|---|---|---|---|
| `Cut=` | Kiểu cắt | round | round, oval, princess, cushion, emerald, asscher, baguette, marquise, pear, heart, trillion, radiant, cabochon_round, cabochon_oval |
| `Size=` | Kích thước (dài / đường kính) | 1.3 | 0.3 … 30 |
| `Width=` | Chiều rộng (0 = tỉ lệ chuẩn) | 0 | 0 … 30 |
| `Material=` | Chất liệu | diamond | diamond, moissanite, cz, ruby, sapphire, emerald, amethyst, topaz, garnet, aquamarine, peridot, tanzanite |
| `VerticalOffset=` | Lệch theo pháp tuyến | 0 | -5 … 5 |
| `Angle=` | Góc xoay | 0 | -180 … 180 |
| `Flip=` | Lật đá | No |  |
| `Spacing=` | Vòng khoảng cách | 0.15 | 0 … 3 |
| `Copy=` | Đặt liên tục | Yes |  |
