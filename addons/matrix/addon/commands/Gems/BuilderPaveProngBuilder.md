# Pavé Prong Builder

Đặt chấu chung cho pavé: một chấu giữa mỗi 3 viên kề nhau và chấu ở cạnh hở.

- **Mã lệnh:** `BuilderPaveProngBuilder`
- **Vị trí:** menu Gems, ô số 24
- **Icon:** `Resources/icons/gems-minimal/BuilderPaveProngBuilder.svg`
- **Gọi bằng dòng lệnh:** `BuilderPaveProngBuilder`, `PaveProng`
- **Cách chạy:** từng bước trên dòng lệnh, kèm bảng BUILDERS; Enter để tạo, Esc để huỷ

## Cách dùng

1. Chọn các viên pavé.
2. Chỉnh kích thước, cao, sâu.
3. Enter.

## Tuỳ chọn (lệnh phụ)


| Dòng lệnh | Ý nghĩa | Mặc định | Khoảng |
|---|---|---|---|
| `Size=` | Cỡ chấu so với đá | 30 | 5 … 100 |
| `Height=` | Cao trên gờ | 0.4 | 0 … 5 |
| `Drop=` | Sâu dưới gờ | 1 | 0 … 10 |
| `Reach=` | Khe tối đa coi là kề nhau | 0.4 | 0 … 5 |
| `Edges=` | Chấu ở cạnh hở | Yes |  |
