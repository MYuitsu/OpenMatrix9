# Match Attributes

Chép style (chấu, bezel, head, dao cắt) từ một viên sang các viên khác và dựng lại.

- **Mã lệnh:** `OthersMatchAttributes`
- **Vị trí:** menu Gems, ô số 28
- **Icon:** `Resources/icons/gems-minimal/OthersMatchAttributes.svg`
- **Gọi bằng dòng lệnh:** `OthersMatchAttributes`, `MatchAttributes`, `gvMatchAttributes`
- **Cách chạy:** từng bước trên dòng lệnh, kèm bảng BUILDERS; Enter để tạo, Esc để huỷ

## Cách dùng

1. Chọn các viên nhận style, Enter.
2. Chọn viên có style, Enter.

## Tuỳ chọn (lệnh phụ)


| Dòng lệnh | Ý nghĩa | Mặc định | Khoảng |
|---|---|---|---|
| `Prongs=` | Chép chấu | Yes |  |
| `Bezel=` | Chép bezel | Yes |  |
| `Head=` | Chép head | Yes |  |
| `Cutter=` | Chép dao cắt | Yes |  |
| `Material=` | Chép chất liệu | No |  |
