# Gem Flow

Dời đá giữ nguyên hình (rigid) từ đường gốc sang đường đích.

- **Mã lệnh:** `BuilderGVDGemFlow`
- **Vị trí:** menu Gems, ô số 31
- **Icon:** `Resources/icons/gems-minimal/BuilderGVDGemFlow.svg`
- **Gọi bằng dòng lệnh:** `BuilderGVDGemFlow`, `GemFlow`
- **Cách chạy:** từng bước trên dòng lệnh, kèm bảng BUILDERS; Enter để tạo, Esc để huỷ

## Cách dùng

1. Chọn đá, đường gốc (trước) rồi đường đích.
2. Enter.

## Tuỳ chọn (lệnh phụ)

- Copy, Stretch.

| Dòng lệnh | Ý nghĩa | Mặc định | Khoảng |
|---|---|---|---|
| `Copy=` | Giữ đá gốc | No |  |
| `Stretch=` | Kéo theo chiều dài đường đích | Yes |  |
