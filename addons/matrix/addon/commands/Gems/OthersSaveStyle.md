# Save Style

Lưu style của viên đá ra tệp .om9style.

- **Mã lệnh:** `OthersSaveStyle`
- **Vị trí:** menu Gems, ô số 29
- **Icon:** `Resources/icons/gems-minimal/OthersSaveStyle.svg`
- **Gọi bằng dòng lệnh:** `OthersSaveStyle`, `SaveStyle`
- **Cách chạy:** từng bước trên dòng lệnh, kèm bảng BUILDERS; Enter để tạo, Esc để huỷ

## Cách dùng

1. Chọn viên đá có style.
2. Chọn ô (Slot) / thư mục.
3. Enter.

## Tuỳ chọn (lệnh phụ)


| Dòng lệnh | Ý nghĩa | Mặc định | Khoảng |
|---|---|---|---|
| `Folder=` | Thư mục style (trống = ~/OM9 Styles) |  |  |
| `Slot=` | Ô / tên style | 1 |  |
