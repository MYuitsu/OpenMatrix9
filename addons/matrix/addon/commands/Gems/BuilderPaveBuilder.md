# Pavé Builder

Bấm từng viên trên mặt; mỗi viên tự thu nhỏ vừa khe với các viên bên cạnh.

- **Mã lệnh:** `BuilderPaveBuilder`
- **Vị trí:** menu Gems, ô số 22
- **Icon:** `Resources/icons/gems-minimal/BuilderPaveBuilder.svg`
- **Gọi bằng dòng lệnh:** `BuilderPaveBuilder`, `PaveBuilder`
- **Cách chạy:** từng bước trên dòng lệnh, kèm bảng BUILDERS; Enter để tạo, Esc để huỷ

## Cách dùng

1. Chọn mặt (và đá đã có).
2. Bấm điểm.
3. Enter.

## Tuỳ chọn (lệnh phụ)


| Dòng lệnh | Ý nghĩa | Mặc định | Khoảng |
|---|---|---|---|
| `Cut=` | Kiểu cắt | round | round, oval, princess, cushion, emerald, asscher, baguette, marquise, pear, heart, trillion, radiant, cabochon_round, cabochon_oval |
| `Size=` | Kích thước (dài / đường kính) | 1.5 | 0.3 … 30 |
| `Width=` | Chiều rộng (0 = tỉ lệ chuẩn) | 0 | 0 … 30 |
| `Material=` | Chất liệu | diamond | diamond, moissanite, cz, ruby, sapphire, emerald, amethyst, topaz, garnet, aquamarine, peridot, tanzanite |
| `VerticalOffset=` | Lệch theo pháp tuyến | 0 | -5 … 5 |
| `Angle=` | Góc xoay | 0 | -180 … 180 |
| `Flip=` | Lật đá | No |  |
| `Spacing=` | Khe giữa đá | 0.15 | 0 … 3 |
| `MinSize=` | Kích thước nhỏ nhất | 0.8 | 0.3 … 10 |
