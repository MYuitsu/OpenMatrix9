# Tapered Baguette Between Two Curves

Lấp đầy khoảng giữa hai đường cong bằng các baguette vát.

- **Mã lệnh:** `BuilderTaperBagBetweenTwoCurves`
- **Vị trí:** menu Gems, ô số 16
- **Icon:** `Resources/icons/gems-minimal/BuilderTaperBagBetweenTwoCurves.svg`
- **Gọi bằng dòng lệnh:** `BuilderTaperBagBetweenTwoCurves`, `TaperBagBetweenTwoCurves`
- **Cách chạy:** từng bước trên dòng lệnh, kèm bảng BUILDERS; Enter để tạo, Esc để huỷ

## Cách dùng

1. Chọn hai đường cong.
2. Chỉnh số đá / chiều dài, khoảng cách.
3. Enter.

## Tuỳ chọn (lệnh phụ)


| Dòng lệnh | Ý nghĩa | Mặc định | Khoảng |
|---|---|---|---|
| `Count=` | Số đá (0 = theo chiều dài) | 0 | 0 … 500 |
| `Length=` | Dài đá | 1.5 | 0.3 … 20 |
| `Spacing=` | Khoảng cách | 0.1 | 0 … 3 |
| `Inset=` | Thụt vào từ đường cong | 0.1 | 0 … 3 |
| `Material=` | Chất liệu | diamond | diamond, moissanite, cz, ruby, sapphire, emerald, amethyst, topaz, garnet, aquamarine, peridot, tanzanite |
