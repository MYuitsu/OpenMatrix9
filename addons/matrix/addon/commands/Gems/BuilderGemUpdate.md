# Gem Update

Dựng lại mesh đá từ thông tin đá (sau khi chỉnh tay hoặc đổi tỉ lệ).

- **Mã lệnh:** `BuilderGemUpdate`
- **Vị trí:** menu Gems, ô số 34
- **Icon:** `Resources/icons/gems-minimal/BuilderGemUpdate.svg`
- **Gọi bằng dòng lệnh:** `BuilderGemUpdate`, `gvGemUpdater`, `GemUpdate`
- **Cách chạy:** từng bước trên dòng lệnh; Enter để tạo, Esc để huỷ

## Cách dùng

1. Chọn đá.
2. Chọn Gem Update, Enter.
