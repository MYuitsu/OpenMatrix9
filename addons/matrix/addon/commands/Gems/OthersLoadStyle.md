# Load Style

Nạp style từ tệp .om9style và dựng lên các viên đá đã chọn.

- **Mã lệnh:** `OthersLoadStyle`
- **Vị trí:** menu Gems, ô số 30
- **Icon:** `Resources/icons/gems-minimal/OthersLoadStyle.svg`
- **Gọi bằng dòng lệnh:** `OthersLoadStyle`, `LoadStyle`
- **Cách chạy:** từng bước trên dòng lệnh, kèm bảng BUILDERS; Enter để tạo, Esc để huỷ

## Cách dùng

1. Chọn đá.
2. Chọn ô (Slot) / thư mục.
3. Enter.

## Tuỳ chọn (lệnh phụ)


| Dòng lệnh | Ý nghĩa | Mặc định | Khoảng |
|---|---|---|---|
| `Folder=` | Thư mục style (trống = ~/OM9 Styles) |  |  |
| `Slot=` | Ô / tên style | 1 |  |
