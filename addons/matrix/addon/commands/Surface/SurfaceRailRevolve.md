# Rail Revolve

Xoay profile quanh trục, bán kính theo đường ray.

- **Mã lệnh:** `SurfaceRailRevolve`
- **Vị trí:** menu Surface, ô số 17
- **Icon:** `Resources/icons/surface-minimal/SurfaceRailRevolve.svg`
- **Gọi bằng dòng lệnh:** `SurfaceRailRevolve`, `RailRevolve`
- **Cách chạy:** từng bước trên dòng lệnh; Enter để tạo, Esc để huỷ

## Cách dùng

1. Chọn profile rồi ray.
2. Bấm hai điểm trục.
