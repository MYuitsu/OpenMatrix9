# Set Surface Tangent

Đặt hướng tiếp tuyến của một mép mặt.

- **Mã lệnh:** `SurfaceSurfaceEditToolsSetSurfaceTangent`
- **Vị trí:** menu Surface, ô số 39
- **Icon:** `Resources/icons/surface-minimal/SurfaceSurfaceEditToolsSetSurfaceTangent.svg`
- **Gọi bằng dòng lệnh:** `SurfaceSurfaceEditToolsSetSurfaceTangent`, `SetSrfTangent`
- **Cách chạy:** từng bước trên dòng lệnh; Enter để tạo, Esc để huỷ

## Cách dùng

1. Chọn mặt.
2. Bấm gần mép, rồi bấm hướng.
