# Heightfield from Image

Mặt nổi theo độ sáng ảnh (PNG, BMP, PGM).

- **Mã lệnh:** `SurfaceHeightfieldfromImage`
- **Vị trí:** menu Surface, ô số 30
- **Icon:** `Resources/icons/surface-minimal/SurfaceHeightfieldfromImage.svg`
- **Gọi bằng dòng lệnh:** `SurfaceHeightfieldfromImage`, `Heightfield`
- **Cách chạy:** từng bước trên dòng lệnh, kèm bảng BUILDERS; Enter để tạo, Esc để huỷ

## Cách dùng

1. Chọn tệp ảnh, kích thước.
2. Bấm góc dưới trái.

## Tuỳ chọn (lệnh phụ)


| Dòng lệnh | Ý nghĩa | Mặc định | Khoảng |
|---|---|---|---|
| `File=` | Tệp ảnh (PNG, BMP, PGM) |  |  |
| `Width=` | Rộng | 20 | 0.5 … 500 |
| `Height=` | Cao tối đa | 1 | 0.01 … 100 |
| `Density=` | Mật độ | 60 | 4 … 300 |
| `Invert=` | Đảo sáng / tối | No |  |
