# Edit Points On

Bật điểm trên đường cong (đường đi qua điểm) / đỉnh lưới để sửa: bấm điểm, bấm chỗ mới, Enter xong.

- **Mã lệnh:** `TopIconEditPointsOn`
- **Vị trí:** menu Top 11, ô số 2
- **Icon:** `Resources/icons/core-minimal/TopIconEditPointsOn.svg`
- **Gọi bằng dòng lệnh:** `TopIconEditPointsOn`, `EditPtOn`
- **Cách chạy:** từng bước trên dòng lệnh; Enter để tạo, Esc để huỷ

## Cách dùng

1. Chọn đường cong / lưới.
2. Bấm điểm cần dời.
3. Bấm (hoặc gõ) vị trí mới. Lặp lại.
4. Enter.
