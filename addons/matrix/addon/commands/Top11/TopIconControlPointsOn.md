# Control Points On

Bật điểm điều khiển (NURBS, polyline, mặt, lưới) để sửa.

- **Mã lệnh:** `TopIconControlPointsOn`
- **Vị trí:** menu Top 11, ô số 3
- **Icon:** `Resources/icons/core-minimal/TopIconControlPointsOn.svg`
- **Gọi bằng dòng lệnh:** `TopIconControlPointsOn`, `PointsOn`, `F10`
- **Cách chạy:** từng bước trên dòng lệnh; Enter để tạo, Esc để huỷ

## Cách dùng

1. Chọn vật.
2. Bấm điểm cần dời.
3. Bấm (hoặc gõ) vị trí mới. Lặp lại.
4. Enter.
