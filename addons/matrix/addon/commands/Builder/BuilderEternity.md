# Eternity Band

Nhẫn eternity kênh: đá chạy quanh cả vòng, có kênh giữ đá và dao cắt cho từng viên.

- **Mã lệnh:** `BuilderEternity`
- **Vị trí:** menu Builder, ô số 1
- **Icon:** `Resources/icons/builder-minimal/BuilderEternity.svg`
- **Gọi bằng dòng lệnh:** `BuilderEternity`, `Eternity`, `gvEternity`
- **Cách chạy:** từng bước trên dòng lệnh, kèm bảng BUILDERS; Enter để tạo, Esc để huỷ

## Cách dùng

1. Chọn cỡ nhẫn, kiểu đá, kích thước (vd. 1.5 hoặc 1.5,1.2 xen kẽ).
2. Chỉnh rộng, khoảng cách, phủ kênh, culet tới ngón.
3. Enter.

## Tuỳ chọn (lệnh phụ)


| Dòng lệnh | Ý nghĩa | Mặc định | Khoảng |
|---|---|---|---|
| `SizeSystem=` | Hệ cỡ nhẫn | us | us, iso, diameter |
| `RingSize=` | Cỡ nhẫn | 7 | 0 … 80 |
| `Width=` | Rộng bản | 3 | 1 … 20 |
| `CuletToFinger=` | Culet tới ngón | 0.3 | 0 … 5 |
| `GemSpacing=` | Khoảng cách đá | 0.1 | 0 … 3 |
| `ChannelWidth=` | Kênh phủ đá | 85 | 50 … 120 |
| `Cut=` | Kiểu cắt | round | round, oval, princess, cushion, emerald, asscher, baguette, marquise, pear, heart, trillion, radiant, cabochon_round, cabochon_oval |
| `Sizes=` | Cỡ đá (xen kẽ: 1.5,1.2) | 1.5 |  |
| `Material=` | Chất liệu | diamond | diamond, moissanite, cz, ruby, sapphire, emerald, amethyst, topaz, garnet, aquamarine, peridot, tanzanite |
| `DrawBand=` | Vẽ bản nhẫn | Yes |  |
