# Text on Curve

Chữ chạy theo đường cong: nằm trên CPlane hoặc đứng hướng ra ngoài; dạng nét hoặc khối.

- **Mã lệnh:** `TextOnCurve`
- **Vị trí:** menu Builder, ô số 5
- **Icon:** `Resources/icons/builder-minimal/TextOnCurve.svg`
- **Gọi bằng dòng lệnh:** `TextOnCurve`, `TextOnCurve`
- **Cách chạy:** từng bước trên dòng lệnh, kèm bảng BUILDERS; Enter để tạo, Esc để huỷ

## Cách dùng

1. Chọn đường cong.
2. Gõ chữ, cao, khoảng cách.
3. Enter.

## Tuỳ chọn (lệnh phụ)


| Dòng lệnh | Ý nghĩa | Mặc định | Khoảng |
|---|---|---|---|
| `Text=` | Chữ | OM9 |  |
| `Height=` | Cao chữ | 2 | 0.2 … 50 |
| `Spacing=` | Khoảng cách chữ | 20 | 0 … 200 |
| `Start=` | Bắt đầu cách đầu đường | 0 | 0 … 500 |
| `Solid=` | Chữ khối | Yes |  |
| `Stroke=` | Nét (0 = tự động) | 0 | 0 … 5 |
| `Flip=` | Lật | No |  |
| `Facing=` | Hướng chữ | cplane | cplane, outward |
