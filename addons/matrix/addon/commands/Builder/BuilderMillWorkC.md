# Mill Work Across

Dao cắt khía ngang dọc đường cong (knurl).

- **Mã lệnh:** `BuilderMillWorkC`
- **Vị trí:** menu Builder, ô số 16
- **Icon:** `Resources/icons/builder-minimal/BuilderMillWorkC.svg`
- **Gọi bằng dòng lệnh:** `BuilderMillWorkC`, `MillWorkC`
- **Cách chạy:** từng bước trên dòng lệnh, kèm bảng BUILDERS; Enter để tạo, Esc để huỷ

## Cách dùng

1. Chọn đường cong.
2. Chỉnh cỡ, khoảng cách.
3. Enter.

## Tuỳ chọn (lệnh phụ)


| Dòng lệnh | Ý nghĩa | Mặc định | Khoảng |
|---|---|---|---|
| `Shape=` | Kiểu | bead | bead, v |
| `Size=` | Cỡ | 0.5 | 0.05 … 5 |
| `Spacing=` | Khoảng cách | 0.1 | 0 … 5 |
| `Depth=` | Sâu | 0.25 | 0 … 5 |
