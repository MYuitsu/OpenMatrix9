# Boolean Difference

Trừ khối: chọn khối bị trừ, rồi chọn dao (khối trừ).

- **Mã lệnh:** `SolidDifference`
- **Vị trí:** menu Solid, ô số 2
- **Icon:** `Resources/icons/solid-minimal/SolidDifference.svg`
- **Gọi bằng dòng lệnh:** `SolidDifference`, `BooleanDifference`, `Difference`
- **Cách chạy:** từng bước trên dòng lệnh; Enter để tạo, Esc để huỷ

## Cách dùng

1. Chọn khối bị trừ, Enter.
2. Chọn khối dùng để trừ, Enter.
