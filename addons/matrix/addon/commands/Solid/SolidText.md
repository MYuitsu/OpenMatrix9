# Text

Tạo chữ nổi (khối) từ chuỗi chữ, cao và dày tuỳ chọn.

- **Mã lệnh:** `SolidText`
- **Vị trí:** menu Solid, ô số 8
- **Icon:** `Resources/icons/solid-minimal/SolidText.svg`
- **Gọi bằng dòng lệnh:** `SolidText`, `TextObject`
- **Cách chạy:** từng bước trên dòng lệnh, kèm bảng BUILDERS; Enter để tạo, Esc để huỷ

## Cách dùng

1. Gõ chữ ở bảng BUILDERS (Text=…), chỉnh Height, Depth.
2. Bấm điểm bắt đầu.

## Tuỳ chọn (lệnh phụ)

- Text: nội dung (A–Z, 0–9, - . & ♥).
- Height: cao chữ.
- Depth: dày (nổi).
- Stroke: nét chữ (0 = tự động).

| Dòng lệnh | Ý nghĩa | Mặc định | Khoảng |
|---|---|---|---|
| `Text=` | Nội dung chữ | OM9 |  |
| `Height=` | Cao chữ | 3 | 0.2 … 50 |
| `Depth=` | Dày chữ | 0.5 | 0.05 … 20 |
| `Stroke=` | Nét chữ (0 = tự động) | 0 | 0 … 5 |
