# Micro Prong Cutter

Dao khía giữa các viên đá kề nhau, để lại chấu micro.

- **Mã lệnh:** `BuilderMicroProngCutter`
- **Vị trí:** menu Cutters, ô số 4
- **Icon:** `Resources/icons/cutters-minimal/BuilderMicroProngCutter.svg`
- **Gọi bằng dòng lệnh:** `BuilderMicroProngCutter`, `gvMicroProngCutter`, `MicroProng`
- **Cách chạy:** từng bước trên dòng lệnh, kèm bảng BUILDERS; Enter để tạo, Esc để huỷ

## Cách dùng

1. Chọn hàng đá.
2. Chọn Micro Prong Cutter, chỉnh Width, Height, Depth, Overlap.
3. Enter.

## Tuỳ chọn (lệnh phụ)

- Width: rộng khía, % đá nhỏ hơn.
- Height / Depth: trên / dưới gờ, %.
- Overlap: ăn vào mỗi viên, %.

| Dòng lệnh | Ý nghĩa | Mặc định | Khoảng |
|---|---|---|---|
| `Width=` | Rộng khía (% đá) | 30 | 5 … 100 |
| `Height=` | Trên gờ (% đá) | 60 | 0 … 200 |
| `Depth=` | Dưới gờ (% đá) | 80 | 0 … 300 |
| `Overlap=` | Ăn vào đá (%) | 20 | 0 … 100 |
