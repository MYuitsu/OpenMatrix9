# Bright Cutter

Hai rãnh chữ V dọc hai bên hàng đá.

- **Mã lệnh:** `BuilderBrightCutter`
- **Vị trí:** menu Cutters, ô số 6
- **Icon:** `Resources/icons/cutters-minimal/BuilderBrightCutter.svg`
- **Gọi bằng dòng lệnh:** `BuilderBrightCutter`, `gvBrightCutter`
- **Cách chạy:** từng bước trên dòng lệnh, kèm bảng BUILDERS; Enter để tạo, Esc để huỷ

## Cách dùng

1. Chọn hàng đá.
2. Chọn Bright Cutter, chỉnh Offset, Width, Depth, Height, Extension.
3. Enter.

## Tuỳ chọn (lệnh phụ)

- Offset: cách gờ đá.
- Width / Depth: miệng và sâu rãnh (mm).
- Height: miệng rãnh so với gờ.
- Extension: kéo dài qua hai đầu.

| Dòng lệnh | Ý nghĩa | Mặc định | Khoảng |
|---|---|---|---|
| `Offset=` | Cách gờ | 0.1 | -2 … 5 |
| `Width=` | Miệng rãnh | 0.6 | 0.05 … 5 |
| `Depth=` | Sâu rãnh | 0.4 | 0.05 … 5 |
| `Height=` | Miệng rãnh so với gờ | 0.1 | -5 … 5 |
| `Extension=` | Kéo dài hai đầu | 0.3 | 0 … 10 |
