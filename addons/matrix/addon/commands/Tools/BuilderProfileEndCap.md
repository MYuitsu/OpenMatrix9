# Profile End Cap

Tạo nắp bo tròn ở đầu profile.

- **Mã lệnh:** `BuilderProfileEndCap`
- **Vị trí:** menu Tools, ô số 23
- **Icon:** `Resources/icons/tools-minimal/BuilderProfileEndCap.svg`
- **Gọi bằng dòng lệnh:** `BuilderProfileEndCap`, `ProfileEndCap`
- **Cách chạy:** từng bước trên dòng lệnh, kèm bảng BUILDERS; Enter để tạo, Esc để huỷ

## Cách dùng

1. Chọn profile kín.
2. Chỉnh độ nhô.
3. Enter.

## Tuỳ chọn (lệnh phụ)

- Flip: đảo chiều.

| Dòng lệnh | Ý nghĩa | Mặc định | Khoảng |
|---|---|---|---|
| `Amount=` | Độ nhô | 1.5 | 0.05 … 20 |
| `Flip=` | Đảo chiều | No |  |
