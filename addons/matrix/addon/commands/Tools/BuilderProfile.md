# Profile

Đặt profile thư viện (phẳng, D, comfort, knife, tròn) ở Top view.

- **Mã lệnh:** `BuilderProfile`
- **Vị trí:** menu Tools, ô số 21
- **Icon:** `Resources/icons/tools-minimal/BuilderProfile.svg`
- **Gọi bằng dòng lệnh:** `BuilderProfile`, `Profile`
- **Cách chạy:** từng bước trên dòng lệnh, kèm bảng BUILDERS; Enter để tạo, Esc để huỷ

## Cách dùng

1. Chọn kiểu, rộng, cao.
2. Bấm vị trí.

## Tuỳ chọn (lệnh phụ)


| Dòng lệnh | Ý nghĩa | Mặc định | Khoảng |
|---|---|---|---|
| `Shape=` | Kiểu profile | comfort | flat, d, comfort, knife, round |
| `Width=` | Rộng | 4 | 0.2 … 50 |
| `Height=` | Cao | 2 | 0.2 … 50 |
