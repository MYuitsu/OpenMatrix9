# Smart MSR

Dời / xoay / co các smart target quanh điểm blend của chúng.

- **Mã lệnh:** `gvSmartMSR`
- **Vị trí:** menu Tools, ô số 15
- **Icon:** `Resources/icons/tools-minimal/gvSmartMSR.svg`
- **Gọi bằng dòng lệnh:** `gvSmartMSR`, `SmartMSR`
- **Cách chạy:** từng bước trên dòng lệnh; Enter để tạo, Esc để huỷ

## Cách dùng

1. Chọn smart target, Enter.
2. Gõ góc, tỉ lệ; bấm điểm dời.
