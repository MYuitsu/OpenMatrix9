# Mesh

Đổi mặt / khối sang lưới.

- **Mã lệnh:** `BuilderMesh`
- **Vị trí:** menu Tools, ô số 28
- **Icon:** `Resources/icons/tools-minimal/BuilderMesh.svg`
- **Gọi bằng dòng lệnh:** `BuilderMesh`, `Mesh`
- **Cách chạy:** từng bước trên dòng lệnh, kèm bảng BUILDERS; Enter để tạo, Esc để huỷ

## Cách dùng

1. Chọn vật.
2. Enter.

## Tuỳ chọn (lệnh phụ)

- DeleteInput: xoá vật gốc.

| Dòng lệnh | Ý nghĩa | Mặc định | Khoảng |
|---|---|---|---|
| `DeleteInput=` | Xoá vật gốc | No |  |
