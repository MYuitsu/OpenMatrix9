# Profile Merge

Gộp hai profile kín chồng nhau thành một.

- **Mã lệnh:** `BuilderProfileMerge`
- **Vị trí:** menu Tools, ô số 22
- **Icon:** `Resources/icons/tools-minimal/BuilderProfileMerge.svg`
- **Gọi bằng dòng lệnh:** `BuilderProfileMerge`, `ProfileMerge`
- **Cách chạy:** từng bước trên dòng lệnh; Enter để tạo, Esc để huỷ

## Cách dùng

1. Chọn hai profile.
2. Enter.
