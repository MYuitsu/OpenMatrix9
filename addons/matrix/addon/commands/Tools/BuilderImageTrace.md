# Image Trace

Dò ảnh (PNG, BMP, PGM) thành đường cong theo ngưỡng tối.

- **Mã lệnh:** `BuilderImageTrace`
- **Vị trí:** menu Tools, ô số 17
- **Icon:** `Resources/icons/tools-minimal/BuilderImageTrace.svg`
- **Gọi bằng dòng lệnh:** `BuilderImageTrace`, `ImageTrace`
- **Cách chạy:** từng bước trên dòng lệnh, kèm bảng BUILDERS; Enter để tạo, Esc để huỷ

## Cách dùng

1. Chọn tệp ảnh trong bảng BUILDERS.
2. Chỉnh rộng, ngưỡng.
3. Bấm góc dưới trái.

## Tuỳ chọn (lệnh phụ)


| Dòng lệnh | Ý nghĩa | Mặc định | Khoảng |
|---|---|---|---|
| `File=` | Tệp ảnh (PNG, BMP, PGM) |  |  |
| `Width=` | Rộng kết quả | 20 | 0.5 … 500 |
| `Threshold=` | Ngưỡng tối | 50 | 1 … 99 |
| `Smooth=` | Làm mượt | Yes |  |
