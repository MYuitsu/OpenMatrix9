# 3D Printing Supports

Thêm sprue và đế đỡ để in 3D.

- **Mã lệnh:** `Builder3dPrinting`
- **Vị trí:** menu Tools, ô số 20
- **Icon:** `Resources/icons/tools-minimal/Builder3dPrinting.svg`
- **Gọi bằng dòng lệnh:** `Builder3dPrinting`, `3dPrinting`, `RingSupportSprue`
- **Cách chạy:** từng bước trên dòng lệnh, kèm bảng BUILDERS; Enter để tạo, Esc để huỷ

## Cách dùng

1. Chọn vật.
2. Chỉnh số sprue, đường kính.
3. Enter.

## Tuỳ chọn (lệnh phụ)


| Dòng lệnh | Ý nghĩa | Mặc định | Khoảng |
|---|---|---|---|
| `Sprues=` | Số sprue | 3 | 1 … 12 |
| `Diameter=` | Đường kính sprue | 1.2 | 0.2 … 5 |
| `Length=` | Dài sprue | 4 | 0.5 … 30 |
| `Base=` | Đế | Yes |  |
