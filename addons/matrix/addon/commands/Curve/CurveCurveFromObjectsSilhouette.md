# Silhouette

Đường bao của vật nhìn theo pháp tuyến CPlane (Rhino Silhouette).

- **Mã lệnh:** `CurveCurveFromObjectsSilhouette`
- **Vị trí:** menu Curve, ô số 53
- **Icon:** `Resources/icons/curve-minimal/CurveCurveFromObjectsSilhouette.svg`
- **Gọi bằng dòng lệnh:** `CurveCurveFromObjectsSilhouette`, `Silhouette`
- **Cách chạy:** từng bước trên dòng lệnh; Enter để tạo, Esc để huỷ

## Cách dùng

1. Select objects for silhouette creation, Enter.
