# Extract Angle Isocurve

Lấy đường cắt mặt theo góc so với trục x của CPlane qua điểm bấm.

- **Mã lệnh:** `CurveGVExtractIsocurve`
- **Vị trí:** menu Curve, ô số 43
- **Icon:** `Resources/icons/curve-minimal/CurveGVExtractIsocurve.svg`
- **Gọi bằng dòng lệnh:** `CurveGVExtractIsocurve`, `AngleIsocurve`
- **Cách chạy:** từng bước trên dòng lệnh; Enter để tạo, Esc để huỷ

## Cách dùng

1. Chọn mặt, Enter.
2. Gõ góc.
3. Bấm điểm.
