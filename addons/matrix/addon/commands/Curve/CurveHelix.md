# Helix

Vẽ đường xoắn lò xo như Rhino Helix: trục và bán kính; Vertical, AroundCurve.

- **Mã lệnh:** `CurveHelix`
- **Vị trí:** menu Curve, ô số 30
- **Icon:** `Resources/icons/curve-minimal/CurveHelix.svg`
- **Gọi bằng dòng lệnh:** `CurveHelix`, `Helix`
- **Cách chạy:** từng bước trên dòng lệnh; Enter để tạo, Esc để huỷ

## Cách dùng

1. Start of axis, End of axis.
2. Radius and start point.

## Tuỳ chọn (lệnh phụ)

- Diameter/Radius.
- Mode=Turns/Pitch, Turns=10, Pitch=1.
- ReverseTwist=No.
- Vertical, AroundCurve.
