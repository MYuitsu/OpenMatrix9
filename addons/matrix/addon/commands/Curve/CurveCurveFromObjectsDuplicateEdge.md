# Duplicate Edge

Sao chép cạnh của mặt/khối/lưới thành đường cong (Rhino DupEdge).

- **Mã lệnh:** `CurveCurveFromObjectsDuplicateEdge`
- **Vị trí:** menu Curve, ô số 39
- **Icon:** `Resources/icons/curve-minimal/CurveCurveFromObjectsDuplicateEdge.svg`
- **Gọi bằng dòng lệnh:** `CurveCurveFromObjectsDuplicateEdge`, `DupEdge`
- **Cách chạy:** từng bước trên dòng lệnh; Enter để tạo, Esc để huỷ

## Cách dùng

1. Select edges to duplicate, Enter.
