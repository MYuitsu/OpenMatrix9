# Arc Blend

Nối hai đầu đường cong bằng hai cung tròn tiếp xúc (Rhino ArcBlend).

- **Mã lệnh:** `CurveBlendCurvesArcBlend`
- **Vị trí:** menu Curve, ô số 57
- **Icon:** `Resources/icons/curve-minimal/CurveBlendCurvesArcBlend.svg`
- **Gọi bằng dòng lệnh:** `CurveBlendCurvesArcBlend`, `ArcBlend`
- **Cách chạy:** từng bước trên dòng lệnh; Enter để tạo, Esc để huỷ

## Cách dùng

1. Select first curve near end.
2. Select second curve near end.
3. Chỉnh tuỳ chọn, Enter.

## Tuỳ chọn (lệnh phụ)

- AlternateSolution: lấy lời giải dài hơn.
- RadiusDifference: chênh lệch bán kính hai cung (dạng chữ S).
- Join: nối với hai đường cong.
