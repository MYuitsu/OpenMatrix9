# Chamfer Curves

Vát góc giữa hai đường cong như Rhino Chamfer; khoảng vát đo từ giao điểm.

- **Mã lệnh:** `CurveChamferCurves`
- **Vị trí:** menu Curve, ô số 23
- **Icon:** `Resources/icons/curve-minimal/CurveChamferCurves.svg`
- **Gọi bằng dòng lệnh:** `CurveChamferCurves`, `Chamfer`, `ChamferCrv`
- **Cách chạy:** từng bước trên dòng lệnh; Enter để tạo, Esc để huỷ

## Cách dùng

1. Select first curve to chamfer: bấm phía cần giữ.
2. Select second curve to chamfer.

## Tuỳ chọn (lệnh phụ)

- Distances=1,1 (gõ Distances=a,b).
- Join=No.
- Trim=Yes.
- ExtendArcsBy=Arc/Line.
