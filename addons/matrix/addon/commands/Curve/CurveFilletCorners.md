# Fillet Corners

Bo tròn mọi góc của đường gấp khúc (Rhino FilletCorners).

- **Mã lệnh:** `CurveFilletCorners`
- **Vị trí:** menu Curve, ô số 22
- **Icon:** `Resources/icons/curve-minimal/CurveFilletCorners.svg`
- **Gọi bằng dòng lệnh:** `CurveFilletCorners`, `FilletCorners`
- **Cách chạy:** từng bước trên dòng lệnh; Enter để tạo, Esc để huỷ

## Cách dùng

1. Select curves to fillet corners, Enter.
2. Radius <1>: gõ bán kính.
