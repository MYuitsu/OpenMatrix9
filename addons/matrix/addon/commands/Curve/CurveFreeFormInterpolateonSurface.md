# Interpolate on Surface

Đường cong qua điểm nằm trên mặt (Rhino InterpCrvOnSrf).

- **Mã lệnh:** `CurveFreeFormInterpolateonSurface`
- **Vị trí:** menu Curve, ô số 49
- **Icon:** `Resources/icons/curve-minimal/CurveFreeFormInterpolateonSurface.svg`
- **Gọi bằng dòng lệnh:** `CurveFreeFormInterpolateonSurface`, `InterpCrvOnSrf`
- **Cách chạy:** từng bước trên dòng lệnh; Enter để tạo, Esc để huỷ

## Cách dùng

1. Select surface to draw curve on.
2. Start of curve, Next point, Enter.
