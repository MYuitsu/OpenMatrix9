# Adjust Closed Curve Seam

Dời điểm nối (seam) của đường cong kín (Rhino CrvSeam).

- **Mã lệnh:** `CurveCurveEditToolsAdjustClosedCurveSeam`
- **Vị trí:** menu Curve, ô số 34
- **Icon:** `Resources/icons/curve-minimal/CurveCurveEditToolsAdjustClosedCurveSeam.svg`
- **Gọi bằng dòng lệnh:** `CurveCurveEditToolsAdjustClosedCurveSeam`, `CrvSeam`
- **Cách chạy:** từng bước trên dòng lệnh; Enter để tạo, Esc để huỷ

## Cách dùng

1. Select closed curves for seam adjustment, Enter.
2. New seam point.
