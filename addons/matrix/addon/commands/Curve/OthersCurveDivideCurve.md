# Divide Curve

Chia đường cong thành các đoạn bằng nhau theo số đoạn hoặc theo chiều dài (Rhino Divide): đặt điểm hoặc tách đường.

- **Mã lệnh:** `OthersCurveDivideCurve`
- **Vị trí:** menu Curve, ô số 36
- **Icon:** `Resources/icons/curve-minimal/OthersCurveDivideCurve.svg`
- **Gọi bằng dòng lệnh:** `OthersCurveDivideCurve`, `Divide`
- **Cách chạy:** từng bước trên dòng lệnh; Enter để tạo, Esc để huỷ

## Cách dùng

1. Select curves to divide, Enter.
2. Number of segments <10>: gõ số đoạn, hoặc bấm Length rồi gõ chiều dài mỗi đoạn.

## Tuỳ chọn (lệnh phụ)

- Length: chia theo chiều dài (từ đầu đường cong).
- Split=No: tách đường cong thành các đoạn thay vì đặt điểm.
- MarkEnds=Yes: đặt điểm ở hai đầu.
