# Control Point Curve

Vẽ đường cong theo điểm điều khiển (Rhino Curve).

- **Mã lệnh:** `CurveFreeFormControlPoints`
- **Vị trí:** menu Curve, ô số 41
- **Icon:** `Resources/icons/curve-minimal/CurveFreeFormControlPoints.svg`
- **Gọi bằng dòng lệnh:** `CurveFreeFormControlPoints`, `Curve`
- **Cách chạy:** từng bước trên dòng lệnh; Enter để tạo, Esc để huỷ

## Cách dùng

1. Start of curve.
2. Next point (Enter để xong; Close để khép).

## Tuỳ chọn (lệnh phụ)

- Degree=3.
- PersistentClose=No.
- Close: khép trơn; Sharp=Yes khép gãy.
