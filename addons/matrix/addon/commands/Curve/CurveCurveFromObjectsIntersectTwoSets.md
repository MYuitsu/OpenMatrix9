# Intersect Two Sets

Giao giữa nhóm thứ nhất và nhóm thứ hai (Rhino 5 IntersectTwoSets): điểm cho đường cong, đường giao cho mặt/khối/lưới.

- **Mã lệnh:** `CurveCurveFromObjectsIntersectTwoSets`
- **Vị trí:** menu Curve, ô số 58
- **Icon:** `Resources/icons/curve-minimal/CurveCurveFromObjectsIntersectTwoSets.svg`
- **Gọi bằng dòng lệnh:** `CurveCurveFromObjectsIntersectTwoSets`, `IntersectTwoSets`
- **Cách chạy:** từng bước trên dòng lệnh; Enter để tạo, Esc để huỷ

## Cách dùng

1. Select first set of objects, Enter.
2. Select second set of objects, Enter.
