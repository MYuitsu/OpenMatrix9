# Tween Curves

Tạo các đường cong trung gian giữa hai đường cong (Rhino TweenCurves).

- **Mã lệnh:** `CurveTweenCurves`
- **Vị trí:** menu Curve, ô số 38
- **Icon:** `Resources/icons/curve-minimal/CurveTweenCurves.svg`
- **Gọi bằng dòng lệnh:** `CurveTweenCurves`, `TweenCurves`, `Tween`
- **Cách chạy:** từng bước trên dòng lệnh; Enter để tạo, Esc để huỷ

## Cách dùng

1. Select start curve.
2. Select end curve.
3. Chỉnh Number, MatchMethod, SampleNumber, Flip; xem trước; Enter.

## Tuỳ chọn (lệnh phụ)

- Number=1: số đường trung gian.
- MatchMethod=None/Refit/SamplePoints.
- SampleNumber=10.
- Flip: đảo hướng đường cuối.
