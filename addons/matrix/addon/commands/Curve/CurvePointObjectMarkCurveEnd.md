# Mark Curve End

Đặt điểm tại cuối đường cong (Rhino CrvEnd).

- **Mã lệnh:** `CurvePointObjectMarkCurveEnd`
- **Vị trí:** menu Curve, ô số 33
- **Icon:** `Resources/icons/curve-minimal/CurvePointObjectMarkCurveEnd.svg`
- **Gọi bằng dòng lệnh:** `CurvePointObjectMarkCurveEnd`, `CrvEnd`, `MarkEnd`
- **Cách chạy:** từng bước trên dòng lệnh; Enter để tạo, Esc để huỷ

## Cách dùng

1. Select curves for end point, Enter.
