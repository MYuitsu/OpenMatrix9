# Project

Chiếu đường cong và điểm thẳng xuống mặt theo pháp tuyến CPlane (Rhino Project); tách đường khi ra ngoài mặt.

- **Mã lệnh:** `CurveCurveFromObjectsProject`
- **Vị trí:** menu Curve, ô số 16
- **Icon:** `Resources/icons/curve-minimal/CurveCurveFromObjectsProject.svg`
- **Gọi bằng dòng lệnh:** `CurveCurveFromObjectsProject`, `Project`, `ProjectCrv`
- **Cách chạy:** từng bước trên dòng lệnh; Enter để tạo, Esc để huỷ

## Cách dùng

1. Select curves and points to project, Enter.
2. Select surfaces, polysurfaces and meshes to project onto, Enter.

## Tuỳ chọn (lệnh phụ)

- Loose=No: Yes chỉ dời điểm điều khiển.
- DeleteInput=No.
