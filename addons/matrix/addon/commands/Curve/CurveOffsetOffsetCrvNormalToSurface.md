# Offset Curve Normal to Surface

Dời đường cong trên mặt theo pháp tuyến của mặt (Rhino OffsetNormal).

- **Mã lệnh:** `CurveOffsetOffsetCrvNormalToSurface`
- **Vị trí:** menu Curve, ô số 56
- **Icon:** `Resources/icons/curve-minimal/CurveOffsetOffsetCrvNormalToSurface.svg`
- **Gọi bằng dòng lệnh:** `CurveOffsetOffsetCrvNormalToSurface`, `OffsetNormal`, `OffsetNormalToSrf`
- **Cách chạy:** từng bước trên dòng lệnh; Enter để tạo, Esc để huỷ

## Cách dùng

1. Select curve on surface.
2. Select surface.
3. Offset distance <1>: gõ khoảng hoặc bấm.
