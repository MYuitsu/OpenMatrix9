# Mean Curve

Tạo đường cong ở giữa hai đường cong (Rhino MeanCrv).

- **Mã lệnh:** `CurveMeanCurve`
- **Vị trí:** gõ tên lệnh trên dòng lệnh hoặc tìm bằng F6
- **Icon:** `Resources/icons/curve-minimal/CurveMeanCurve.svg`
- **Gọi bằng dòng lệnh:** `CurveMeanCurve`, `MeanCrv`, `MeanCurve`
- **Cách chạy:** từng bước trên dòng lệnh; Enter để tạo, Esc để huỷ

## Cách dùng

1. Select first curve.
2. Select second curve: đường giữa được tạo ngay (chọn sẵn hai đường rồi gọi lệnh cũng được).

## Tuỳ chọn (lệnh phụ)

- AdjustCurveDirections=Yes: tự đảo đường thứ hai cho cùng chiều với đường thứ nhất.
