# Apply UV Curves

Áp đường cong phẳng lên mặt theo UV (Rhino ApplyCrv).

- **Mã lệnh:** `CurveCurveFromObjectsApplyUVCurves`
- **Vị trí:** menu Curve, ô số 25
- **Icon:** `Resources/icons/curve-minimal/CurveCurveFromObjectsApplyUVCurves.svg`
- **Gọi bằng dòng lệnh:** `CurveCurveFromObjectsApplyUVCurves`, `ApplyCrv`
- **Cách chạy:** từng bước trên dòng lệnh; Enter để tạo, Esc để huỷ

## Cách dùng

1. Select curves to apply and the surface to apply them to, Enter.
