# Fillet Curves

Bo cung tròn giữa hai đường cong như Rhino Fillet: chỗ bấm trên mỗi đường quyết định phần được giữ.

- **Mã lệnh:** `CurveFilletCurves`
- **Vị trí:** menu Curve, ô số 21
- **Icon:** `Resources/icons/curve-minimal/CurveFilletCurves.svg`
- **Gọi bằng dòng lệnh:** `CurveFilletCurves`, `Fillet`, `FilletCrv`
- **Cách chạy:** từng bước trên dòng lệnh; Enter để tạo, Esc để huỷ

## Cách dùng

1. Select first curve to fillet: bấm đường thứ nhất ở phía cần giữ.
2. Select second curve to fillet: bấm đường thứ hai; cung bo tạo ngay.

## Tuỳ chọn (lệnh phụ)

- Radius=1 (0 = kéo hoặc cắt tới góc nhọn).
- Join=No: nối thành một đường.
- Trim=Yes: cắt hoặc kéo dài hai đường tới điểm tiếp xúc.
- ExtendArcsBy=Arc/Line: kéo dài cung bằng cung hay đoạn thẳng.
