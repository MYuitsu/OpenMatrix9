# Curve from 2 Views Builder

Như Crv2View (bản Builder của Matrix).

- **Mã lệnh:** `BuilderCrv2ViewHistory`
- **Vị trí:** menu Curve, ô số 14
- **Icon:** `Resources/icons/curve-minimal/BuilderCrv2ViewHistory.svg`
- **Gọi bằng dòng lệnh:** `BuilderCrv2ViewHistory`, `Crv2ViewBuilder`, `gvCrv2ViewHistory`
- **Cách chạy:** từng bước trên dòng lệnh; Enter để tạo, Esc để huỷ

## Cách dùng

1. Select first curve.
2. Select second curve.
