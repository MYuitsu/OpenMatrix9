# Curve Boolean

Phép toán vùng giữa các đường cong phẳng (Rhino CurveBoolean): bấm vào các vùng cần giữ, ra đường cong kín đúng theo đường gốc.

- **Mã lệnh:** `CurveCurveEditToolsCurveBoolean`
- **Vị trí:** menu Curve, ô số 37
- **Icon:** `Resources/icons/curve-minimal/CurveCurveEditToolsCurveBoolean.svg`
- **Gọi bằng dòng lệnh:** `CurveCurveEditToolsCurveBoolean`, `CurveBoolean`, `CrvBoolean`
- **Cách chạy:** từng bước trên dòng lệnh; Enter để tạo, Esc để huỷ

## Cách dùng

1. Select curves to perform boolean operation, Enter.
2. Click inside the regions to keep: bấm vào vùng (bấm lại để bỏ).
3. Enter để tạo.

## Tuỳ chọn (lệnh phụ)

- DeleteInput=None/All/Used.
- CombineRegions=Yes: gộp các vùng kề nhau.
- AllRegions: chọn mọi vùng.
