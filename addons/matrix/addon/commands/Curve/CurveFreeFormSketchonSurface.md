# Sketch on Surface

Phác thảo trên mặt (Matrix: _Sketch _OnSurface=Yes).

- **Mã lệnh:** `CurveFreeFormSketchonSurface`
- **Vị trí:** menu Curve, ô số 46
- **Icon:** `Resources/icons/curve-minimal/CurveFreeFormSketchonSurface.svg`
- **Gọi bằng dòng lệnh:** `CurveFreeFormSketchonSurface`, `SketchOnSrf`
- **Cách chạy:** từng bước trên dòng lệnh; Enter để tạo, Esc để huỷ

## Cách dùng

1. Select surface to sketch on.
2. Start of sketch, Next point of sketch, Enter.
