# Polyline on Surface

Đường gấp khúc nằm trên mặt.

- **Mã lệnh:** `BuilderPolylineOnSurface`
- **Vị trí:** menu Curve, ô số 48
- **Icon:** `Resources/icons/curve-minimal/BuilderPolylineOnSurface.svg`
- **Gọi bằng dòng lệnh:** `BuilderPolylineOnSurface`, `PolylineOnSrf`, `gvPolylineOnSurface`
- **Cách chạy:** từng bước trên dòng lệnh; Enter để tạo, Esc để huỷ

## Cách dùng

1. Select surface for polyline.
2. Start of polyline, Next point of polyline, Enter.
