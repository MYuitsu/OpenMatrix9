# Rectangle

Vẽ hình chữ nhật: hai góc, từ tâm, 3 điểm hoặc đứng; có thể bo góc cung tròn hoặc conic.

- **Mã lệnh:** `CurveRectangleCornertoCorner`
- **Vị trí:** menu Curve, ô số 4
- **Icon:** `Resources/icons/curve-minimal/CurveRectangleCornertoCorner.svg`
- **Gọi bằng dòng lệnh:** `CurveRectangleCornertoCorner`, `Rectangle`
- **Cách chạy:** từng bước trên dòng lệnh; Enter để tạo, Esc để huỷ

## Cách dùng

1. Bấm góc thứ nhất.
2. Bấm góc đối diện, hoặc gõ chiều dài rồi chiều rộng (Enter = hình vuông).

## Tuỳ chọn (lệnh phụ)

- 3Point: hai đầu một cạnh rồi chiều rộng.
- Vertical: đứng vuông góc mặt phẳng làm việc.
- Center: từ tâm.
- Rounded: bo góc; gõ bán kính hoặc bấm điểm mà góc bo đi qua; Corner=Arc/Conic, Rho cho góc conic.
