# Scale 1D

Phóng to/thu nhỏ theo một hướng.

- **Mã lệnh:** `TransformScaleScale1D`
- **Vị trí:** menu Transform, ô số 3
- **Icon:** `Resources/icons/transform-minimal/TransformScaleScale1D.svg`
- **Gọi bằng dòng lệnh:** `TransformScaleScale1D`, `Scale1D`
- **Cách chạy:** từng bước trên dòng lệnh; Enter để tạo, Esc để huỷ

## Cách dùng

1. Chọn vật.
2. Bấm điểm gốc và hướng.
3. Gõ hệ số.
