# Array Polar

Mảng tròn quanh tâm.

- **Mã lệnh:** `TransformArrayPolar`
- **Vị trí:** menu Transform, ô số 9
- **Icon:** `Resources/icons/transform-minimal/TransformArrayPolar.svg`
- **Gọi bằng dòng lệnh:** `TransformArrayPolar`, `ArrayPolar`
- **Cách chạy:** từng bước trên dòng lệnh; Enter để tạo, Esc để huỷ

## Cách dùng

1. Chọn vật.
2. Bấm tâm.
3. Gõ số lượng và góc.

## Tuỳ chọn (lệnh phụ)

- NumberOfItems, Angle.
