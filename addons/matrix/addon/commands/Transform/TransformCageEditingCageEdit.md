# Cage Edit

Biến dạng vật theo các điểm cage đã dời.

- **Mã lệnh:** `TransformCageEditingCageEdit`
- **Vị trí:** menu Transform, ô số 20
- **Icon:** `Resources/icons/transform-minimal/TransformCageEditingCageEdit.svg`
- **Gọi bằng dòng lệnh:** `TransformCageEditingCageEdit`, `CageEdit`
- **Cách chạy:** từng bước trên dòng lệnh; Enter để tạo, Esc để huỷ

## Cách dùng

1. Chọn cage và vật.
2. Enter.
