# Scale by Plane

Phóng to/thu nhỏ đều trong mặt CPlane, giữ chiều cao.

- **Mã lệnh:** `TransformScaleScaleByPlane`
- **Vị trí:** menu Transform, ô số 30
- **Icon:** `Resources/icons/transform-minimal/TransformScaleScaleByPlane.svg`
- **Gọi bằng dòng lệnh:** `TransformScaleScaleByPlane`, `ScaleByPlane`
- **Cách chạy:** từng bước trên dòng lệnh; Enter để tạo, Esc để huỷ

## Cách dùng

1. Chọn vật cần biến đổi (hoặc chọn sau khi gọi lệnh, Enter).
2. Bấm điểm gốc.
3. Gõ hệ số.

## Tuỳ chọn (lệnh phụ)

- Copy: giữ bản gốc.
