# Scale 2D

Phóng to/thu nhỏ trong mặt CPlane.

- **Mã lệnh:** `TransformScaleScale2D`
- **Vị trí:** menu Transform, ô số 2
- **Icon:** `Resources/icons/transform-minimal/TransformScaleScale2D.svg`
- **Gọi bằng dòng lệnh:** `TransformScaleScale2D`, `Scale2D`
- **Cách chạy:** từng bước trên dòng lệnh; Enter để tạo, Esc để huỷ

## Cách dùng

1. Chọn vật.
2. Bấm điểm gốc.
3. Gõ hệ số.
