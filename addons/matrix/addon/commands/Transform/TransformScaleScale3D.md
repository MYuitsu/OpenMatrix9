# Scale 3D

Phóng to/thu nhỏ đều.

- **Mã lệnh:** `TransformScaleScale3D`
- **Vị trí:** menu Transform, ô số 1
- **Icon:** `Resources/icons/transform-minimal/TransformScaleScale3D.svg`
- **Gọi bằng dòng lệnh:** `TransformScaleScale3D`, `Scale`
- **Cách chạy:** từng bước trên dòng lệnh; Enter để tạo, Esc để huỷ

## Cách dùng

1. Chọn vật.
2. Bấm điểm gốc.
3. Gõ hệ số hoặc bấm hai điểm tham chiếu.
