# Orient 3 Points

Đưa vật từ 3 điểm tham chiếu tới 3 điểm đích.

- **Mã lệnh:** `TransformOrient3Points`
- **Vị trí:** menu Transform, ô số 6
- **Icon:** `Resources/icons/transform-minimal/TransformOrient3Points.svg`
- **Gọi bằng dòng lệnh:** `TransformOrient3Points`, `Orient3Pt`
- **Cách chạy:** từng bước trên dòng lệnh; Enter để tạo, Esc để huỷ

## Cách dùng

1. Chọn vật cần biến đổi (hoặc chọn sau khi gọi lệnh, Enter).
2. Bấm 3 điểm tham chiếu.
3. Bấm 3 điểm đích.

## Tuỳ chọn (lệnh phụ)

- Copy, Scale.
