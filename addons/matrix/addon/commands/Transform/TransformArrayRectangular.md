# Array

Mảng lưới chữ nhật.

- **Mã lệnh:** `TransformArrayRectangular`
- **Vị trí:** menu Transform, ô số 25
- **Icon:** `Resources/icons/transform-minimal/TransformArrayRectangular.svg`
- **Gọi bằng dòng lệnh:** `TransformArrayRectangular`, `Array`
- **Cách chạy:** từng bước trên dòng lệnh; Enter để tạo, Esc để huỷ

## Cách dùng

1. Chọn vật.
2. Gõ số theo X, Y, Z.
3. Bấm/gõ khoảng cách.
