These excerpts were split from the Matrix 8/9 and Rhino 5 manuals and are the behavioural reference for this folder. Pages marked as shared in a text header also contain content of neighbouring sections, so verify against the original PDF when a boundary page matters. Entries marked 'linked from L2' live once in the parent L2 reference folder and are not duplicated here.
