## Scale By Plane
Copy=Yes/No: Specifies whether or not the
objects are copied. A plus sign appears at the
cursor when copy mode is ON.
‘ScaleByPlane’
Changes the size of selected objects in two
directions using different lengths for each
direction.
Plane: Specifies the plane by which the object
will Scale.
ActiveCPlane: Uses the active Construction
plane as the Reference plane.
Where is this Command:
Access this command from Transform>Scale By
Plane
Steps:
3Point: Pick three points to specify the
Reference plane.
Object: Select a planar object to specify a
Reference plane.
• Select Scale By Plane from the Transform menu.
• Select objects to Scale.
• Pick an origin point and set the plane for scaling.
• Select the first Reference point.
• Select the second Reference point.
FromView: Uses the specified View plane as a
Reference plane.
WorldTop: Uses the World XY plane as the
current Reference plane.
Example: Origin point is center of object and
first Reference point is to the object’s right edge.
Using ‘ActiveCPlane’ dragging the object in the
Perspective viewport, move the mouse left/right
to scale in the first direction and up/down to scale
in the second direction.
WorldRight: Uses the World YZ plane as the
current Reference plane.
Scaling is set by the Plane and Viewport in which
the object is selected.
WorldFront: Use the World XZ plane as the
current Reference plane.
## Stretch
‘Stretch’
Scales the selected area of an object in one
direction.
Floral design before Scale By Plane.
Where is this Command:
Access this command from Transform>Stretch
Steps:
• Select Stretch from the Transform menu.
• Select object(s) to Stretch..
• Press Enter when done.
• Pick the Start of the Stretch axis.
• Pick the End of the Stretch axis.
Floral design after Scale By Plane.
