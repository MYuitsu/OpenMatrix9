### Diamond Cut:
Creates a diamond cut custom gem stone.
Flips the direction of the culet. Helpful if your

Curve: With this option ‘ON’ the gems being
placed are constrained to the surface and a
selected curve. This is like Gem on Curve but
each stone is placed manually.
Gems: With this option selected you can add
existing stones to the Gem on Surface command.
These existing stones could be laid out using
any gem tool but now will have a spacing guide
appear when the stone you are placing is in
proximity.
Reset: Will return the builder to it’s default
settings.
