## Pavé Builder
This more basic of the two Pavé builders
creates a hexagonal pattern only, but allows you
to select exact gem number, size and spacing.
• In the Pavé Builder menu, highlight a gem size
and type a quantity over where the quantity “1”
is located. Start with smaller quantities to assure
that the exact number desired is added to the
design and fills the entire space.
• If needed, use the arrows up and down to view the
entire list of gem sizes. Then, use Gem Reporter
or Design Report to verify the size and number of
gems used.
• Click “Get Start Point” and click a place on the
surface, such as the Midpoint, from which to
start the pavé layout.
Where is this builder:
Access this builder from Gems>Pavé Builder
At this point, the gray preview gems will appear.
Changing the start point may change the look of

Steps:
• Select Pavé Builder from the Gems menu.
• Input a surface or polysurface in the Surface in-

• Click “Add Gems” and select a size from the Gem

### Adjust Sliders to Change Layout:
### Options:
Angle: Angle moves the preview
gems by rotating them around the
Start Point.
Hexagonal Toggle: Select this “Hexagonal”
option to toggle off circular azures and
toggle on hexagon-shaped azures.
Azure Depth: Azure Depth affects
the location of the middle circle
preview which
defines the size and angle of the
azure cut.
Minimum Spacing: The Minimum
Spacing is the minimum amount the
gems are positioned between each
other. The gems will get no closer
than this value.
Azure Size: The Azure Size
represents the bottom preview
curve, the hexagonal azure,
where the cut will exit the bottom
surface.
Spacing: The Spacing amount is the
maximum amount the gems are
placed apart from
each other.
Through Hole: The Through Hole
slider represents the size of the
middle preview
curve.
Set Gems to Finish: When you like the results
of the builder, use “Set Gems” to turn the gray
preview gems into real gems.
Reset: Use “Reset” to begin again like new.
Seat Angle: The Seat Angle
preview curve represents the size
and location of the seat
of the gems.
## Pavé Azure Builder
Set Azures: When you like the results, click “Set
Azures” to add the azures to the
model.
After creating Pavé and using the related
tools like Gem on Surface and Gem Springs
to perfect the design, add azures. Azure Builder
works for hexagonal patterns only.
Hint: For best results, choose a new layer color
before using “Set Azures” so you can select the
results easily.
## Pavé Prong Builder
Where is this builder:
Access this command from Gems>Pavé Azure
Builder
Add prongs to pavé layout - touching sides
of layout, 2 gems, & 3 gems at once.
Steps:
Where is this builder:
Access this builder from Gems>Pavé Prong
Builder
Steps:
• Start with an existing Pavé layout created with
Pavé Builder.
• Select Pavé Azure Builder from the Gems menu.
• Begin by inputting the “Top” surface on which you
placed the gems during Pavé builder.
• Enter the bottom surface. The “Bottom” surface is
the back surface of the pavé, or, where the holes
will be.
• Input the “Gems” and the Azure previews will
appear.
• Select Pavé Prong Builder from the Gems menu.
• Input the surface on which the pavé layout lies into
the builder.
• Input the gems from the pavé layout into the
builder.
• Adjust the prongs setting using the sliders.
