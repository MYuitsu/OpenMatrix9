# Orient to Gem

### Options:
Apply: Commit the changes within the Gem
Guide menu with the Apply button.
View Gem: This option is only
available when a single gem is
selected. This will activate Gem
View with the selected stone.
Show Guide: Adds a reference gem located
at F4 in the viewport. Use this to assist in
modeling the object you want oriented to the
gems. This reference gem is locked, Use the
Unlock command if you wish to interact with the
reference gem.
View Reset: Returns the
viewports from Gem View to their
default view.
Reset: Returns the builder to it’s default settings.
Note: Each icon in the Gem Guide menu can be
toggled ‘ON’ and ‘OFF’. When a tool is active, a
yellow square surrounds the icon. The tools will
remain active until the icon is toggled to the ‘OFF’
position.
## Orient to Gem
The guide gem comes out locked at F4
gvOrientGems’
Orient and scale an object or group of objects to
gems within the viewport.
Scale to Gem: When this option is selected the
Guide gem will be scaled to 10mm in size.
Set to Gems: Orients the input object in the
Object box to the gems in the Gems box.
Where is this Command:
Access this command from Gems>Orient to
Gem
Steps:
• Select Orient to Gem from the Gem menu.
• Input the gems from the viewport into the Gems
input box.
• Input the object you want to orient to the gems in
the Object input box.
When you click on set to gems the objects in the
object box are oriented to the gems in the gems
box.
Undo Orient: Reverts object to the state before
you performed the orient
