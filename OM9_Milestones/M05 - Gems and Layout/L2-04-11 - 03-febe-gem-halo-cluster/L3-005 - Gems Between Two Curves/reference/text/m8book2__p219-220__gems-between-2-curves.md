Where is this Command:
Access this command from Gems>Gems
Between 2 Curves
or select Gems Between from the F6 menu
when a pair of curves is selected
Point A: Set position of the
baguette along the curve. Adjust in
the builder by selecting the Point A
icon at the left in the builder and
running the slider below-or typing a
percentage along the curve in the box. You can
also use the Pink Sphere Viewport Control Handle
on the curve.
Steps:
Point B: Set position of the
baguette along the curve. Adjust in
the builder by selecting the Point
B icon at the left in the builder and
running the slider below-or typing a
percentage along the curve in the box. You can
also use the Pink Sphere Viewport Control Handle
on the curve.
• With nothing selected in the viewport, select
Gems Between 2 Curves from the Gem menu.
• Indicate spacing in the Command Line.
• Select two curves to use in the builder. Gems
will touch both curves-so the curves should be
roughly the same length.
• Confirm the Start location and table direction are
in the right location.
• The start point will be indicated by the word start.
The direction of the gems tables will be indicated
by a series of white lines appearing on the curve.
• Press enter to set the gems.
Gems automatically taper and bend between
the input curves.
### Command Line Options:
Spacing: Define the amount of space between
each stone.
Use the Viewport Control Handles to determine the
location and dimensions of the tapered baguette.
### Options:
Flip: Flips the orientation of the baguette so that
it reverses from its current direction.
Mode=Spacing/Shape: Choose whether
the builder conforms perfectly to the spacing
parameter that you set or to the shape of the
curves. The builder cannot do both at the same
time.
Reset: Will return the builder to it’s default
settings.
AutoSpacing=Yes/No: With this turned ‘ON’,
the end gem will try and fall at the end of the two
curves, which will affect the rest of the layout.
## Gems Between 2 Curves
‘
gvGemsBetween2Crvs’
Assign spacing between gems and select two
curves to create a gem layout that touches both
curves.
GemTop=On/Off: With GemTop ‘OFF’ the
girdles of the stones will be even with the curves.
With GemTops ‘ON’ the table will be even with
the curves.

## Cluster Builder
Creates a Cluster head around a existing stone.
Where is this Command:
Access this command from Gems>Cluster
Builder
XY Offset: The First box represents in mm the
distance between
the center stone
and the accent
stones on the XY
axis. Type the
desired offset into
the box.
There are stages to the Cluster Builder-Edge
Gems, Under Bezels and Prong Work. We will
address each stage individually. You can use
each stage individually or in conjunction with one
another.
### Edge Gems:
This stage will create a gem profile as well as
the edge gems for the cluster according to your
specifications.
Z Offset: The next box
represents in mm the
distance between the center
stone and the accent stones
on the Z axis. Positive values
move down negative values
move up.  Type the desired
offset into the box.
Steps:
Degree: This box indicates
the angle or degree of
rotation of the gems. Type
the desired degree into the
box.
• Open the Cluster Builder from them Gem Menu.
• Highlight your center stone in the viewport (or
construction curve) and input into the builder’s
gem input box.
• Type in the settings you desire for the gems and
click Add Gems.
• Click Next to proceed to ‘Under Bezels’
Gem Size: Set the size
of the accent gems in
the ‘Edge Gem Size’
drop down.
Number of Gems:
Type in the desired
number of accent
stones-alternatively
you can select ‘Use Maximum Gems’ and Matrix
will add the maximum number of gems given the
parameters.
### Options:
Add Gems: Adds the edge gems to your set
parameters.
Select: Selects all the objects generated in this
stage (edge gems and gem profile).
Undo: Will undo the creation of all the objects
generated in this stage.
