## Baguette Builder
‘gvBaguette’
Create custom baguette shapes to meet precise
dimensions.
### Modes:
The Baguette Builder has three modes; Size,
Move and Rotate. Each mode will be covered
individually.
Where is this Command:
Access this command from Gems>Baguette
Builder
Steps:
Size: This mode gives you control over the
dimensions of the baguette.
• Open the Baguette Builder from them Gem Menu.
• Click on ‘New Baguette’ button in the builder or
input a existing gem into the gem input box.

## Baguette Channel
Steps:
‘gvTaperBagChannel’
Similar to Gems Between 2 Curves, this tool
places baguettes between two curves. You assign
size, taper, spacing, and banking.
• Type a percentage and click on
the green arrow to add a size.
• Select a percentage and click
on remove to delete it from
the list.
Where is this Command:
Access this command from Gems>Baguette
Channel
Steps:
Banking: Controls degrees
of banking you’ll allow in a
nonplanar pair of lines, to
control how the gems “bank”
or rotate as they move through
space when they are laid out.
Steps:
• Type a value and click on  the
green arrow to add a size.
• Select a value and click on
remove to delete from the list.
• Select Baguette Channel from the Gem menu.
• Select 2 curves and input into the Curve box in the
builder.
• The start point of the channel will be indicated by
the word start. The direction of the baguette’s
tables will be indicated by a series of white lines
appearing around the curve.
• Make any necessary adjustments either in the
builder or Command Line.
• Click Apply to see the results.
Spacing: Set the Spacing
between the gems by typing a
value into this field, in mm.
### Editing Dimensions:
### Options:
Size: This lists the sizes of
baguettes that Matrix can pull
from in order to create the
channel.
Flip: Changes the direction that the gem tables
point relative to the surface normal.
Middle: Aligns the first gems start point at the
middle of the gem as opposed to its edge.
