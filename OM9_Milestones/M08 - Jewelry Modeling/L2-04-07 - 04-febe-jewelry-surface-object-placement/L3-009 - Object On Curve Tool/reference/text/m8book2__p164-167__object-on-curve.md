### Command Line Options:
Object Type: Select between Object, Round
Gem, Select a Gem, Sphere (Milgrain) or Browser
(default)
RoundGem: Choose this option to change to
Gem on Curve.
F4/Down/Object: This controls the direction
the object is pointing. For F4 all the objects point
to world center (0,0,0). In Down mode all the
objects point straight down. “Object” points all the
objects to a surface object of your choosing-this
could be a curve, surface or point. Select “Object”
and then select the surface, curve or point to
orient your object.
Flip: Flip reverses the direction of the object so it
points up instead of down.
SelectGem: This option allows you to select a
different gemstone shape from an existing stone
in the viewport. This stone must be positioned at
F4 for the command to work correctly.
Sphere: This option changes the objects to
spheres or beads. This is the same as when you
run the Milgrain/Bead on Curve command.
Gem Tops: For ObjectType=Gem, turning ‘Gem
Tops’ on will position the stone’s table so that it is
flush with the curve. With ‘Gem Tops’ off the stone’
girdle is flush with the curve. This will also orient
your objects in a similar fashion.
Taper Gems: This allows control over the end
size of objects, creating a size control on both
ends of the curve.
Object: This option allows you to layout an
existing viewport object along a curve. For this
command to work correctly the object must be
positioned around F4. See Object Option for
steps to place your objects on a curve.
