# Документы, шаблоны и сохранность работы

## Начать

При первом запуске открывается пример **Куб** — деталь с эскизом и выдавливанием: двойной щелчок по ней в дереве
показывает, как она построена. Дальше программа открывается стартовым экраном: **Новая деталь**, **Новая сборка**,
**Открыть…** и недавние файлы. **Новая деталь** заводит документ с деталью и сразу входит в неё. **Новая сборка** и
**Файл -> Новый проект** заводят пустую сборку: деталь в ней добавляет кнопка **Новая деталь** (клавиша **N**).

## Сохранить и открыть

**Файл -> Сохранить** (Ctrl+S), **Сохранить как…**, **Открыть проект…**. Файл хранит и построение, и готовую
геометрию: большой проект открывается сразу, без пересчёта. Если в документе есть несохранённые правки, программа
спросит, сохранить ли их, прежде чем открыть другой или создать новый.

## Свойства документа

![Свойства документа: они уезжают вместе с файлом.](img/doc-props.png)

**Файл -> Свойства документа…**: название, автор, версия, комментарий и **точность геометрии** едут вместе с файлом —
открывший его видит, чьё это и с какой точностью считать. Дата заведения ставится один раз, при первом сохранении.

## Шаблоны

**Файл -> Сохранить как шаблон** делает текущий документ заготовкой: свойства, точность, опоры, заготовленные
эскизы. **Файл -> Создать из шаблона** заводит новый документ по нему. Новый документ не помнит путь шаблона:
первое «Сохранить» спросит, куда класть, и шаблон не пострадает.

## Автосохранение

Раз в заданный срок программа молча пишет копию рядом с проектом; обычное «Сохранить» её удаляет. Если при открытии
копия окажется новее файла — прошлая работа оборвалась после правок, — строка состояния скажет, где лежит копия:
откройте её через **Файл -> Открыть**. Срок задаётся в настройках (**Автосохранение каждые**); ноль выключает.

## Недавние файлы

**Файл -> Недавние** и стартовый экран. Пути, которых больше нет на диске, из списка выбрасываются; **Очистить
список** убирает все.

## Отмена

**Ctrl+Z** и **Ctrl+Y** (или Ctrl+Shift+Z), с именем шага в меню **Правка**. Глубина истории — **Шагов отмены** в
настройках: больше шагов — больше памяти, снимок крупной сборки весит десятки мегабайт.
