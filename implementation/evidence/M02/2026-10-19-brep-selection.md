- `om9-core::brep::Brep` owns canonical OCCT source and its source-bound disposable display snapshot. The document keeps BRep as `Geometry::Brep`, never converting canonical geometry into a Mesh. - The existing `brep_kernel::BrepBody` is a portable topology/handle-contract fixture, with an unlinked backend and no exact surface/source serialization. It is preserved. The new document record does not pretend that fixture reconstructs a native solid or introduce another persistent native-handle store.
- `om9-kernel` extends its existing complete-operation bridge with source serialization/read, tessellation, actual edge sampling, face/edge adjacency and topological vertices. Native objects are temporary within a synchronous operation. Rust copies bounded immutable arrays, assigns UUIDs and owns all retained state. This C++ exception is limited to required OCCT APIs; no QymCAD code was copied and no native pointer reaches the UI or document.
- Native array offsets are snapshot-local mapping data. Face/edge/vertex UUIDs persist with the canonical source snapshot and `.om9` document. A rebuilt snapshot receives new IDs and must be published as a new geometry revision. Existing `SourceStamp` and publication checks refuse stale picks, including after Undo; there is no attempt to guess topology correspondence after editing.
- Scene buffers remain disposable mesh data. Picking maps their triangles/edge samples/actual vertices back to BRep UUIDs. Tessellation diagonals and interior display samples cannot become selectable BRep edges/vertices. Hit positions on curved faces/edges follow the display tessellation within its requested deflection; this is not an exact native surface projection or a new snap solver.
- Ctrl+Shift keeps root, complete nested member path, BRep subset UUID, source and publication. The controller rejects forged keys or mesh subsets for a BRep. The common overlay draws original topological face boundaries, including inner wires, and selected edge/vertex feedback in all four panes. Whole-object Gumball previews/commits use the existing Rust placement/transaction owner.
- `.om9` round trips preserve canonical source, UUIDs, object ID and placement. Native tests reparse the saved source and measure its actual volume; geometry is not proved from bounding boxes. 3DM BRep conversion, topology-changing modeling commands and exact native hit projection are outside this M02 implementation scope.
