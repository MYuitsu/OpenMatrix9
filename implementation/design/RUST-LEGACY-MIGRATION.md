## Method and limits

- Verdicts for the large domains come from reading the target crates during the
  2026-10-17 assessment (`CURATED` in the generator); the rest use a name-match heuristic
  and are marked *unverified*.
- A verdict is a **candidate**, never completion: a behaviour counts as migrated only when a
  target test proves it, per AGENTS.md. `PORT` means "no counterpart found", not "absent".
- `LEGACY_HOST` (`*_ffi`, menu/toolbar/workbench shells) exists only because the legacy host is
  FreeCAD/Qt; the target calls Rust APIs directly, so the boundary is not ported.
