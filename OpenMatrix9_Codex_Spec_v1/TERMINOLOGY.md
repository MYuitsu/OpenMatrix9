# Thuật ngữ dùng trong OpenMatrix9

| Thuật ngữ | Ý nghĩa |
|---|---|
| Feature ID | Định danh ổn định của một mục trong catalog. |
| Command | Lệnh được gọi từ menu, CMD hoặc tương tác phù hợp. |
| Builder | Workflow cấu hình nhiều tham số, preview và tạo kết quả. |
| F6 | Menu ngữ cảnh phụ thuộc selection. |
| CPlane | Mặt phẳng dựng hình của view/session. |
| History | Quan hệ input/output cho tái tạo; phân biệt với danh sách lệnh đã chạy. |
| Ring Rail | Đường tham chiếu kích thước/vị trí vòng nhẫn. |
| Gem | Đối tượng đá có identity, hình dạng, kích thước và orientation. |
| Setting | Geometry kim loại giữ/bao đá như head, bezel, prong. |
| Cutter | Geometry dùng để cắt vật liệu trong bước Boolean. |
| SubD | Mô hình topology điều khiển và bề mặt chia nhỏ. |
| NURBS | Biểu diễn curve/surface có degree, knots và control points. |
| MSR | Tương tác Move / Scale / Rotate. |
| Operation plan | Snapshot request đã kiểm tra cấu trúc; chưa phải geometry đã tính. |
| Supported slice | Phạm vi native cụ thể đã triển khai/nghiệm thu. |

Kiểu dữ liệu, đơn vị, default và topology phải theo từng feature. Nếu chưa xác
định, ghi rõ điểm còn thiếu thay vì suy ra từ tên thuật ngữ.
