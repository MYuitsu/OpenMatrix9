# OM9-RENDER-001 — Ground Plane

Alias tương thích: `Chưa có alias command`. Nhóm: `13-render`. Trạng thái: `not_started`.

## Hợp đồng thiết kế

Ground Plane tạo đối tượng nền cho renderer, hoặc dùng object nền tự chọn. Create Ground Plane đặt trong viewport; chọn nền và áp Ground Plane material qua Material Editor. Kích thước/phân bố mặc định chưa được xác lập.
