# OM9-GEM-007 — Gem Profile Curve

Alias tương thích: `gvGemProfile`. Nhóm: `10-gems`. Trạng thái: `not_started`.

## Hợp đồng thiết kế

gvGemProfile lấy profile quanh girdle, preview có handles rồi Enter. Với stone tại F4: Width theo X, Height theo Y, Tilt quanh Y, Twist quanh X, Roll quanh Z, X/Y/Z Offset. Edit chỉnh Sweep Edit Points, Move về handles thường; Select Rail gắn profile để Profile Placer đặt; Add duplicate; Reset.

## Vai trò đầu vào của mẫu

Cardinality là chính sách của ví dụ; các nhánh tương tác và loại geometry phải được host kiểm tra tiếp theo hợp đồng.

| Role key | Kiểu | Tối thiểu | Tối đa |
|---|---|---:|---:|
| `Gem` | `gem` | 1 | 1 |
| `Rail` | `curve` | 0 | 1 |

## Hướng dẫn triển khai

1. Rust: tạo trạng thái riêng cho `OM9-GEM-007` và các vai trò Gem, Rail; phân biệt đầu vào bị thiếu với tùy chọn chưa đặt. Đọc girdle từ gem metadata, tạo curve parametric có frame của gem rồi áp size/rotation/offset; lưu profile identity và sweep points.
2. C++/Qt: đăng ký và điều phối native command `gvGemProfile`; chuyển kế hoạch Gem Profile Curve sang adapter FreeCAD theo phép toán đã nêu; kiểm tra kết quả và hiển thị lỗi theo bước. Dựng đối tượng xem trước ngoài tài liệu, rồi commit trong một transaction; Cancel bỏ bản xem trước. Giữ command disabled nếu adapter cần thiết chưa có.
3. Python: chỉ đăng ký workbench và cung cấp fixture tích hợp cho `OM9-GEM-007`; menu dùng bộ điều phối command native của C++/Qt.
