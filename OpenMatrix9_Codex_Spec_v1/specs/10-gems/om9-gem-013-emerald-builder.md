# OM9-GEM-013 — Emerald Builder

Alias tương thích: `gvEmerald`. Nhóm: `10-gems`. Trạng thái: `not_started`.

## Hợp đồng thiết kế

gvEmerald dùng New Emerald hoặc gem hiện có. Size mode Length, Width, Depth từ table tới culet, Girdle Thickness, Corner length; Move X/Y/Z và Rotate X/Y/Z giúp đặt ngay trong builder; Enter set gem. Không suy số facet hoặc cut proportions chưa nêu.

## Vai trò đầu vào của mẫu

Cardinality là chính sách của ví dụ; các nhánh tương tác và loại geometry phải được host kiểm tra tiếp theo hợp đồng.

## Hướng dẫn triển khai

1. Rust: tạo trạng thái riêng cho `OM9-GEM-013` và các vai trò Gem; phân biệt đầu vào bị thiếu với tùy chọn chưa đặt. Sinh emerald asset bằng outline cắt góc và facet scheme tự tác giả, giữ size riêng transform; thay input chỉ sau valid geometry.
2. C++/Qt: đăng ký và điều phối native command `gvEmerald`; chuyển kế hoạch Emerald Builder sang adapter FreeCAD theo phép toán đã nêu; kiểm tra kết quả và hiển thị lỗi theo bước. Dựng đối tượng xem trước ngoài tài liệu, rồi commit trong một transaction; Cancel bỏ bản xem trước. Giữ command disabled nếu adapter cần thiết chưa có.
3. Python: chỉ đăng ký workbench và cung cấp fixture tích hợp cho `OM9-GEM-013`; menu dùng bộ điều phối command native của C++/Qt.
