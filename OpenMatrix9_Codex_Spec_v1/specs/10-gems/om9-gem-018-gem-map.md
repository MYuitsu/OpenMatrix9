# OM9-GEM-018 — Gem Map

Alias tương thích: `gvGemMap`. Nhóm: `10-gems`. Trạng thái: `not_started`.

## Hợp đồng thiết kế

gvGemMap tạo sơ đồ vị trí và kích thước stones trong cửa sổ riêng; cần model có gems. File Print mở dialog; Save PNG/JPEG/Bitmap; Create Layout thêm tab Gem Map trong document. Chế độ xuất file và tạo layout là hai hiệu ứng cần tách.

## Vai trò đầu vào của mẫu

Cardinality là chính sách của ví dụ; các nhánh tương tác và loại geometry phải được host kiểm tra tiếp theo hợp đồng.

| Role key | Kiểu | Tối thiểu | Tối đa |
|---|---|---:|---:|
| `Gems` | `gem` | 1 | Không đặt trong mẫu |
| `Destination` | `path` | 0 | 1 |

## Tham số và điều kiện

Mẫu không tự điền default, không kiểm tra miền số hay tập enum của solver. Các điều kiện này phải được thực thi ở adapter theo bảng và hợp đồng.

| Option key | Kiểu mẫu | Ý nghĩa / đơn vị | Default / trạng thái |
|---|---|---|---|
| `File` | `choice` | Print, Save hoặc Create Layout | Chưa xác lập; mẫu giữ giá trị được nhập hoặc trạng thái hiện hành, không tự điền. |
| `Format` | `choice` | PNG, JPEG hoặc Bitmap khi lưu | Chưa xác lập; mẫu giữ giá trị được nhập hoặc trạng thái hiện hành, không tự điền. |
| `Path` | `text` | Đường dẫn đầu ra do người dùng chọn | Chưa xác lập; mẫu giữ giá trị được nhập hoặc trạng thái hiện hành, không tự điền. |

## Hướng dẫn triển khai

1. Rust: tạo trạng thái riêng cho `OM9-GEM-018` và các vai trò Gems, Destination; phân biệt đầu vào bị thiếu với tùy chọn chưa đặt. Đọc gem positions/shapes/dimensions, chiếu sơ đồ và annotations theo view policy công khai; xuất raster hoặc tạo layout qua transaction riêng.
2. C++/Qt: đăng ký và điều phối native command `gvGemMap`; chuyển kế hoạch Gem Map sang adapter FreeCAD theo phép toán đã nêu; kiểm tra kết quả và hiển thị lỗi theo bước. Giữ thao tác ở phạm vi trạng thái hoặc đầu ra đã chọn. Giữ command disabled nếu adapter cần thiết chưa có.
3. Python: chỉ đăng ký workbench và cung cấp fixture tích hợp cho `OM9-GEM-018`; menu dùng bộ điều phối command native của C++/Qt.

## Các ca nghiệm thu cần thực hiện

- Model không gems báo trạng thái rỗng, map labels đúng cỡ/vị trí; Save không tạo layout, Create Layout có tab Gem Map và Undo.
- OM9-GEM-018: kiểm tra đầu vào sai vai trò, thiếu lựa chọn, NaN và vô cực; lỗi phải giữ nguyên tài liệu. Kiểm tra chuyển chế độ hoặc hủy đầu ra không làm thay đổi hình học.
