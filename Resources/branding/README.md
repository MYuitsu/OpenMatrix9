# OpenMatrix9 branding

The project owner supplied these images for OpenMatrix9 on 2026-10-06.
Both PNG files retain the supplied image bytes.

- `introduction.png`: introduction image displayed in the project README.
- `workbench.png`: FreeCAD workbench selector icon, loaded by `InitGui.py`.

These branding images are separate from the 510 authored SVG command icons.
They are included in the existing CMake Resources copy/install rules.

`launcher/OpenMatrix9.ico` is a format conversion of the supplied `workbench.png`
for the Windows Desktop shortcut, with 16/24/32/48/64/128/256-pixel sizes.
The original PNG remains unchanged; no new branding artwork was generated.
