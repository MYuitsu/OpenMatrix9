# OM9-VIEW-001 — Picture Frame

Status: in progress. Rust placement, original command interaction and embedded native output have been verified. Preview and remaining options are incomplete; this feature must not be counted complete from the current tests.

The local spec requires `PictureFrame`, image selection, corner selection, second reference point or CMD length, retained source aspect ratio, scalable/movable model guide and Shift Ortho. It lists Vertical, SelfIllumination, Left=Self, Right=Self, EmbedBitmap, Autoname and AlphaTrasnparency as option cues, without recovered defaults or full semantics. Those cues remain tracked rather than silently discarded.

Implemented pure geometry uses the current orthonormal right-handed C-plane. Width follows the reference direction projected into its local XY plane; Shift chooses the dominant plane axis. Scalar width follows its X axis. Vertical uses the plane normal as the image height axis. Height is width/source aspect. Native ImagePlane is centered, so the result includes selected corner, center and three orientation axes. These are documented OM9 choices pending native interaction verification, not claims of recovered option defaults. Dimensions are1e-7..1e9 mm; every rectangle corner must have finite coordinates within1e9 mm. Invalid input leaves the C ABI output untouched.

Rust evidence: five feature tests pass, including a failing regression that exposed an intermediate corner exceeding limits while the opposite diagonal remained valid. All38 Rust tests pass; Clippy passes. Native bridge output layout is corner3, center3, x3, y3, normal3, width, height.

Native capability evidence: `tests/core_picture_frame_host_probe.FCMacro` passes eight checks and process exit zero in `build/core_picture_frame_host_probe-1/edf1cc170ba34c37a59c86cd8a2948c1/results.json`. The host supplies Image::ImagePlane with native texture display, editable Placement/XSize/YSize, No shading mode and ImageFile PropertyFileIncluded. Assigning ImageFile first and dimensions afterward preserves target dimensions. Undo/Redo restores the native object. FCStd reload retains the embedded raster after the generated source file is deleted, retains alpha and restores placement/size/display mode.

Implemented native controller: original PictureFrame menu/CMD routes share the image dialog and placement session. It accepts first corner coordinates and positive scalar width, two point inputs, Shift mouse Ortho, Vertical=Yes/No, SelfIllumination=Yes/No and Autoname=Yes/No. Defaults are OM9 choices: current C-plane, nonvertical, self illuminated, autoname and native embedding. Commit is one native Image::ImagePlane transaction; cancelled image browsing, Esc or invalid width create no output. Native Placement/XSize/YSize remain editable for moving/scaling. Switching to Line or interactive zoom cancels the image session; Notes also cancels it. Capture remains read-only and does not consume the session.
