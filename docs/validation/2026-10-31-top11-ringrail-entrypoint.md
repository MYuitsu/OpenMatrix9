# Top11 Ring Rail entrypoint

The M03 runtime record previously said the Top11 Ring Rail button was disabled pending M04. Current standalone code enables the entry when no command is running and dispatches it to the existing M04 Ring Rail builder. This record updates runtime evidence; it does not certify the complete M04 builder or replace its manual gate.

At controller level, Top11 toolbar invocation, `gvRingRail`, `RingRail`, and `Top11 RingRail` each open the builder, accept `Diameter=20`, and apply one radius-10 circle with one RingRail history recipe. Each case checks `.om9` save/open and Undo/Redo. Toolbar and `gvRingRail` cases also reject `Diameter=0`, allow cancellation, and leave the document and undo history unchanged. A nested-instance scene fixture checks seven configured byte limits, exercising both refused and committed operations; refused cases retain the original document, scene object count and undo history. This finite sweep is not a proof of atomicity for every budget or failure.

An egui event test renders the real sidebar, clicks its RingRail icon, sets the diameter through the shared command owner, scrolls the sidebar using a wheel event, and clicks the real builder Apply button. It checks the circle, recipe, Undo and Redo. The test uses simulated egui events and test-only widget rectangle recording; it is not OS pointer input, GPU presentation or human acceptance. The first attempt to click Apply without scrolling failed because the button was below the 720-pixel window; the corrected test scrolls to it and passes.

An explicitly invoked native interoperability test exports and reimports the radius-10 circle for both Top11 toolbar and `gvRingRail` command paths. It checks the geometry and confirms the 3DM export receipt reports dropping one builder history recipe; `.om9` is the tested history-preserving format. The native adapter SHA-256 was `bddca46577747333f9377b379351a077b710158f47ce6e279d7b6e21e6439615`. This is a 3DM I/O test, not an openNURBS measurement batch.

On Windows x64 with `CARGO_TARGET_DIR=L:\om9-target` and `-j 2`, 111 app Top11 tests, 10 builder-panel tests, six `top11_` UI-library tests and the native two-route 3DM test passed. An initial UI test invocation with `--exact` and an incomplete test name selected zero tests; the corrected invocation ran and passed. Other builder options, broader M04 geometry and OS-level desktop interaction remain open. The earlier attempted Computer Use launch was denied by Windows at `GetCursorPos` with error `0x80070005`; no desktop interaction is claimed.
