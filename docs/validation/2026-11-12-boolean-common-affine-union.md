# Boolean Union in a shared affine placement

Boolean Union previously refused two B-reps with the same non-rigid placement. For Union, applying one invertible affine map to the union of local shapes gives the union of those mapped shapes. The product Union path now detects identical non-rigid placement matrices, operates on the existing local B-rep sources, and retains that placement on the new entity. Different placements still use the existing world-space path and its conservative restriction; Boolean Two, Difference, Intersection and Split are not changed by this slice. This does not repair the earlier Boolean failure for an affine transformation already baked into one source.

The controller regression saves and reopens two intersecting unit boxes whose local union has volume 1.5 mm³. It tests the same nonuniform scale, shear, and reflection on both entities, each at display profiles 0.5 and 0.01 mm and through menu dispatch and command submission. It checks the retained placement, analytic world bounds and volume (local volume multiplied by the absolute determinant), and document equality across Undo/Redo. It saves and reopens the result and repeats Union with an input having the same placement. The pre-existing non-rigid-placement regression checks that unequal placements remain refused with document and Redo retained. This is not evidence for arbitrary geometry, tolerances or extreme/ill-conditioned affine maps, imported models, native peak, or desktop. The result remains locally represented with a non-rigid placement; other commands may still refuse or process it differently.

The separate centered sphere/scaled-box fixture still fails when the affine transform is baked into one input. A focused checked-kernel test confirmed that reversing operand order does not fix that fixture: both orders at both display profiles are refused by OCCT result checks. Verification: app Solid controller 81 passed; Solid integration 198 passed/1 ignored; Solid workflows 114 passed/1 ignored; kernel Boolean 80 passed/1 known affine reproducer ignored. No new desktop executable was built or tested.

## Boolean Two Objects with shared placement

Boolean Two now uses the same local-coordinate approach when both inputs have exactly the same non-rigid placement. Its preview retains that placement, and viewport drawing applies it to preview segments; commit assigns it to the result. Other placement combinations still use the existing world path and restriction. Six saved/reopened two-box fixtures cover scale, shear and reflection at two display profiles through menu dispatch and CMD. Each cycles the five preview modes and checks local analytic volumes, preview placement and no document mutation; after cycling back to Union the test commits, checks world bounds and determinant-adjusted volume, and verifies Undo/Redo. The other four modes were checked as previews, not committed in these fixtures. An egui offscreen test checks an actual projected Union preview line at its transformed world position for the scale fixture; this is not desktop or GPU screenshot acceptance.

Verification: 82 Solid controller tests passed; the two Boolean Two viewport tests passed; Solid integration 198 passed/1 ignored, Solid workflows 114 passed/1 ignored, and the no-OCCT fallback test passed. General affine tolerance, unequal placements, imports, native peak and interactive desktop remain open; the original baked-affine failure remains unsolved.

## Difference, Intersection and Split with shared placement

The grouped Difference, Intersection and Split paths now also factor out an identical non-rigid placement, work on local sources, and assign that placement to each output. Eighteen controller fixtures use two intersecting boxes after save/reopen: three operations, scale/shear/reflection and two display profiles, through menu dispatch or CMD. Each checks local analytic volume, placement, world bounds, and Undo/Redo. Split produces two pieces covering the target, not the portion outside it. Two additional in-memory Difference fixtures use two targets and two cutters, covering disjoint cutters and overlapping cutters, with analytic result volumes and Undo/Redo. Different placements were separately refused by all three commands while retaining document and Redo. This does not certify all imported or curved topology, extreme transforms, world-space tolerance, large-model native peak or interactive desktop. The baked-affine Boolean failure remains open.

Verification: 85 Solid controller tests passed; Solid integration 198 passed/1 ignored and Solid workflows 114 passed/1 ignored. No new desktop executable was built or tested.
