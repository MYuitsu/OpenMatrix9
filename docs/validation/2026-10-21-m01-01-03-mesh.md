# Polygon mesh creation through SDK v1 — 2026-10-21

A plugin can now publish a polygon mesh from vertices and face index lists. The slice belongs
to `OM9-L2-01-03` (typed scene entity records: geometry handles) and reuses the core mesh
record validation.

## Changed

| Layer | Change |
|---|---|
| Public SDK | `Host::add_mesh(label, vertices, faces)` and `ObjectAddMesh`; capability entry. |
| Host | Builds `Mesh { vertices, faces, normals: [], colors: [] }`, validates it with `Mesh::validate` (bounded channels, in-range indices, finite points) and stages it through the shared add-output path. |
| Example plugin | `MeshDemo` creates a quad mesh. |
| Tests | Host test for a quad (vertices/faces, `geometry_kind = Mesh`, one Undo) and the out-of-range-index refusal; native DLL test for the mesh geometry, Undo and Redo. |

## Semantics fixed by this slice

- Faces are indices into `vertices`; an out-of-range index is a `mesh` refusal, and the core
  record decides the size/index bounds.
- Normals and per-face colors are not accepted in this version; the mesh stores empty
  channels, so display normals are recomputed by the renderer.
- The mesh publishes as one object in the command's single transaction and one Undo removes
  it.

## Not proved here

- Mesh normals, per-face colors, UVs and texture coordinates are not exposed; the renderer
  recomputes display normals.
- Mesh editing, booleans and repair remain at their owners.
- macOS host and plugin execution are unverified; interactive UI acceptance was not
  performed. No manual or M09 gate was promoted.
