# RCORE-01 — independent Circle History admission — 2026-10-11

Independent persisted Circle options use the existing shared Rust construction policy before native stored-point copies and source extraction. Replay does not consult or mutate the interactive session; existing analytic/deformable/FitPoints/tangent/legacy AroundCurve solvers and recipes are reused.

**Original RCORE-01 and the all-family plan remain in progress.**

## Change and ownership

Rust derives a bounded owned NativeCurve request from the existing Recipe and
Circle options, with stored world-mm points and mm_per_unit1. It uses the same
operation/type/options/backend registry as current construction, rather than
reading the current session. Replay performs that admission before cloning
options or recorded points. Unsupported FromFirst/Solution/Vertical options
outside Tangent and the existing solution budget are no longer bypassed.
The query returns only status and retains no foreign pointers. Header length,
alignment/address arithmetic and the original1024-point limit precede access.
Release panic=abort and native dependencies are not certified memory-safe.

The permanent C++ exception is FreeCAD property resolution, document replay,
native shape construction and typed host diagnostics. It borrows the recipe
and checks count/options and existing Rust scalar world-point bounds before
copies. Existing solidCurveReference and nativeFitPoints accept a synchronous
independent admission callback before private source copy/extraction. Their
current-command callers retain their original default path. Tangent source,
AroundCurve path and point/FitPoints readers now use the stored Circle request.
Dynamic direction/radius and current sample count are checked again before
native solve. Legacy AroundCurve materializes scalar options without rewriting
its original empty Recipe storage. This is input/solve admission; full output
GeometryResult/parameter/attribute provenance is still an original open item.
