# ExtractWireframe: reopened OCCT B-rep, scoped A2-R

On 2026-11-11, a product-controller regression saved a Box as v4, opened it in a fresh controller and reproduced `Unsupported("edge extraction requires attested source topology")`. After the change, the same path extracts all native source edges from one OCCT read and one edge map, without trusting persisted edge UUIDs or indices. The existing attested path remains in place. Rust owns source capture, permission/scene checks, admission, placement and one transaction; the narrow C++ adapter reads the source and emits curves from the same map. Native OCCT parsing, topology mapping and conversion allocations are not bounded by the Rust reservation.

`cargo test -p om9-app --test wireframe --test curve_menu --test dup_border --target-dir L:/om9-target -j 2 -- --test-threads=1`: wireframe 36 passed/3 ignored, curve_menu 6 passed, dup_border 4 passed. The reopened Box test verifies 12 distinct analytic edges, current layer, saved output geometry and one Undo/Redo. Reopened cylinder shell and trimmed arc fixtures exercise two display profiles, rigid placement, menu and command dispatch, sampled curve geometry, trim/orientation checks and a seam in the cylinder fixture. Reopened Sphere with a degenerate edge, multiple roots, a non-rigid placement, an object-count limit and simulated managed-memory pressure preserve document and Redo. The pressure fixture retries successfully after release.

A reopened compound generated by union of disjoint Box and Sphere supplies a later degenerate edge: a separate invocation of the same all-edge adapter observes successful edge-output admissions before the degenerate-edge error, and the controller invocation on the same source returns that error while preserving the full snapshot and Redo. These are two native reads; the observed map order in the adapter run supports the fixture but does not instrument the controller's native read. A separate kernel-callback test also injects admission failure after several output preparations.

Public source audit passed (15,875 source files, 594 icon bindings, 593 SVGs). The build emitted pre-existing unreachable-pattern and unused-method warnings. Three wireframe tests were ignored: two diagnostics and one manual independent OCCT domain fixture; the existing domain evidence remains in `2026-11-10-extractwire-source-first-slice.md`.

The extraction is synchronous in the existing controller; no new cancellation or worker mechanism was added. Source and selection are captured in the exclusive controller call, and the scene epoch and permissions are checked before extraction. There is no independent desktop interaction or measurement of native/process peak for this change. This is not validation of all seam shapes, legacy files, isocurves, standalone surfaces, multiple roots, blocks, NativeBrep, or general affine placements. It does not implement source-only history or display eviction.
