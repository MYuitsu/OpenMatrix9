# Top11 Split/Trim: circle arc intersection domains

The coplanar circle solver previously intersected the underlying complete circles and wrapped each angle using the arc's span, so it reported intersections even when the actual arc intervals did not meet. An authored upper-arc/lower-arc fixture reproduced that false result. The Rust solver now maps each candidate angle through a full turn into each arc interval, enumerates distinct traversals subject to output budgets, and verifies the resulting points against both the candidate and each other using model tolerance. Near an arc endpoint it accepts the endpoint only when it is within tolerance. Parallel circle planes offset within tolerance are handled using projected centers and the returned distance is measured instead of always reported as zero.

The circle-circle calculation scales radii and center distance before squaring, so the tested `1e-200`-radius pair retains two crossings. Core fixtures also cover a single valid upper-arc crossing, disjoint arc intervals, an angle interval crossing zero, a two-turn curve with distinct parameters, a budget refusal, endpoint proximity inside and outside tolerance, and parallel planes offset by 0.0005 mm. A test assertion for the two-turn fraction was corrected from `1/6, 2/3` to `1/12, 7/12` after checking the total angular domain; the production calculation was unchanged by that correction.

Through both CMD and toolbar, Split and Trim reject a nonintersecting cutter without changing the document, then accept a valid upper arc and preserve the actual crossing, `.om9` state and Undo/Redo. A real-native 3DM test exports and imports the Split result and checks both pieces meet at the crossing; native adapter SHA-256 `bddca46577747333f9377b379351a077b710158f47ce6e279d7b6e21e6439615`. This is a 3DM interoperability check, not an openNURBS measurement batch.

Windows x64, `CARGO_TARGET_DIR=L:\om9-target`, `-j 2`: 118 app Top11, 83 Top11 BRep, 34 core Top11, 16 core curve/surface operation and 204 core library tests passed; 118 no-default app Top11 tests passed with existing unused-code/import warnings. Coincident circles and overlapping arcs, nonparallel circle planes, general sampled intersections, extreme angular ranges and desktop UI acceptance remain open.
