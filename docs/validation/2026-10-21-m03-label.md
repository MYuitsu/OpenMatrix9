# Measurement label through SDK v1 — 2026-10-21

A plugin can report one measurement label through the command event log. Owner:
`OM9-L2-03-20` (`OM9-L3-03-20-005`).

## Changed

| Layer | Change |
|---|---|
| Public SDK | `Host::report_measurement(text)`; one request and capability entry. |
| Host | Stages one `Progress` `PluginMessage` under the same bounds as the message service (≤512 bytes, ≤32 per command); empty/oversized text is `message` and a failed command discards the report. |
| Example plugin | `LabelDemo {"id": …}` measures the length and reports `length 10.00 mm`. |
| Tests | Host test for the single progress message and the empty-text refusal; native DLL test that the label appears in the Controller event log. |

## Semantics fixed by this slice

- The label is one Progress line in the existing bounded event log, so the Command line and
  observers see it exactly like other plugin feedback.
- Empty or oversized text is a `message` refusal; a command that later fails discards the
  report with the rest of its staged state.
- Reporting stages no document mutation.
