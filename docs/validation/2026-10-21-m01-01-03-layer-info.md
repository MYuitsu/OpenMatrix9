# Single layer record through SDK v1 — 2026-10-21

A plugin can read one layer record with the same effective permissions as the layer list.
Owner: `OM9-L2-01-03` (`OM9-L3-01-03-004`).

## Changed

| Layer | Change |
|---|---|
| Public SDK | `Host::layer_info(id)` returning `LayerInfo`; one request and capability entry. |
| Host | Refactored the layer-list mapping into one `layer_info` helper so list and single read cannot diverge; `locked` is the effective inversion `!editable`. |
| Tests | Host test that the single record equals the listed record and the unknown-id refusal (`layer`). Native suite unchanged (34) — this slice is host-tested only. |

## Semantics fixed by this slice

- Visible/selectable/locked are the effective permissions after the parent chain; `current`
  is the staged current layer; colour is the record colour.
- List and single read share one helper.
- Reading stages no mutation.
