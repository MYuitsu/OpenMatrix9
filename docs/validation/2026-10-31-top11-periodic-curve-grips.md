# Top11 periodic NURBS control and edit points

For a full-domain NURBS whose repeated periodic basis is certified by the existing Rust validator, Control Points now exposes the independent poles once. Moving a repeated pole updates its periodic counterpart, preserving the repeated basis. Edit Points wraps each independent pole's Greville parameter into the active period and solves the existing rational collocation system with repeated basis contributions accumulated into their shared independent pole. The solver updates repeated poles consistently, preserves weights/knots and validates the resulting basis. Uncertified periodic records and unsupported trimmed periodic intervals remain rejected.

Core tests cover each of four independent points on authored quadratic polynomial and rational examples in both directions. They verify the moved point, all other edit points, repeated controls, closure, preserved weights/knots and rejection of a broken repeated basis. The bounded dense solver retains its existing 512-independent-point cap and singular-system refusal. Application tests cover Edit Points and Control Points through CMD and Top11, translated placement, both curve directions, `.om9` save/open and Undo/Redo. They do not establish behavior for all knot structures, physical pointer/GPU presentation or human acceptance.
