# Top 11 Trim: selected curves cut one another (2026-10-30)

Standalone Rust OM9 on Windows, base `89ef2676b597ebc5ab38fa5c6acf0ad47a2f261b` plus working-tree changes. The normalized M03 reference describes selected objects cutting each other. The previous default instead required separate target and cutter selection; a two-crossing-line regression failed because it was still waiting for cutters.

For selected curves, the default Trim now computes their pairwise intersections, then asks for portions to remove. After each pick, it prepares a prospective set of surviving entities and recomputes intersections for all of them before committing one Undo transaction. Thus any selected curve can be edited, including a curve that previously acted as a cutter, and later picks use the changed geometry. Enter finishes; Cancel retains already committed picks. A single preselected curve starts selection for at least one more. Typed points near multiple targets are rejected as ambiguous; the viewport supplies the selected scene hit explicitly.

Tests cover two selected crossing lines, consecutive edits on both, selection after invoking and from one preselection, three cutters and repeat picks, editing a former cutter after the original splits, disjoint/unhit curves, invalid and ambiguous picks, Cancel and Undo/Redo. The egui viewport test sends a synthetic click; it is not OS/GPU or human acceptance. Existing fixtures were changed to select the participating curves together; earlier separate-cutter receipts remain historical. The shared line intersection path now avoids numeric fallback when the analytic nonparallel test is definitive or exactly parallel lines are separated beyond tolerance; overlapping/nearly parallel cases still use the prior fallback.

With `CARGO_TARGET_DIR=L:\om9-target` and `-j 2`, four core curve/Top 11 suites passed 60 tests, app Top 11/options/OCCT BRep suites passed 76, the no-default Top 11/options suites passed 61, and the focused egui viewport test passed. Endpoint-only open-curve residual removal was subsequently addressed in [the endpoint follow-up](2026-10-30-top11-trim-endpoint-residual.md). The quadratic pairwise work and complex numerical cases are not fully profiled or certified. Only curve objects are admitted; surface/BRep targets, general periodic NURBS, original option details, OS input and M03-UI human acceptance remain open. Historical separate-cutter state machinery remains in source but is not the default invocation path; its eventual removal is technical cleanup, not evidence of completion.
