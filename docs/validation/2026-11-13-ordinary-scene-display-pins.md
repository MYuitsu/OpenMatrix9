# Ordinary OCCT scene display pins

2026-11-13. Accounted application scenes now bind ordinary OCCT B-rep occurrences to tracked display pins before scene publication, including initialization, incremental and full transaction candidates, and Undo/Redo scene construction. Root and definition-member occurrences sharing a display share one lease. The coordinator accepts only a retained or registered immutable candidate document and resolves the root stamp and member path. Unregistered low-level scene captures still have a document-display fallback; NativeBrep still uses its previous route. Document and history still own display, so this does not close C1.

New/Open replacement initially failed because its private candidate had pins in its temporary account before account adoption. The unpublished candidate now releases ordinary pins, adopts the existing account, and rebinds them before publication. A failed admission keeps the old world, scene and Redo. An ordinary scene pin retained after controller teardown keeps the display but not the document and releases the tracked display/topology charge on the last drop. A separate test verifies shared instance lease, candidate registration and stale path rejection. A detached scene object now intentionally retains its own tracked display; the prior test expecting it to release display was updated.
