# Immutable B-rep source shared across document versions

The owned canonical OCCT source text was previously a `String`, so cloning a B-rep copied that text even for placement-only changes. It is now immutable `Arc<String>` storage. The existing serde `rc` support serializes it as the same JSON string field; source hash and display/source binding are unchanged. A red/green unit test checks source allocation identity across clones and JSON decode/equality. This change only shares source text: `BrepDisplay` and its topology arrays are still cloned and remain part of the B-rep object.

At the time of this initial check the retained-storage inventory charged each owning B-rep separately. Subsequent changes deduplicate the source within and across document versions, Undo/Redo and captures; see [the follow-up](2026-11-03-shared-brep-source-accounting.md). The full P0 single-count inventory and P1 source/display separation remain open; this does not remove the 256 MiB limit or provide v5 migration.

On E: default-feature debug builds with `-j 2`, the full core test command passed with two existing ignored benchmarks, and archive tests passed for a 24 KiB B-rep source and seven project codec cases. Six real OCCT B-rep selection tests passed with the `gpu-sphere` feature, including a new placement/Undo/Redo test that verifies shared source identity, stable face IDs and source volume. Five kernel edge-site tests, 17 B-rep picking precision tests, one repeated-instance STL test and the explicitly enabled real native 3DM clipboard B-rep test passed. These checks do not prove memory/performance gains, full source/topology correctness across all adapters, or desktop input behavior.

Eleven gesture regressions passed. The first concurrent run of the 11 offscreen GPU tests was deliberately stopped after eight cases had run for more than 60 seconds and the test process accumulated over 350 seconds of CPU time; no result is claimed for that run. Re-running the same 11 tests with `--test-threads=1 --nocapture` passed in 4.20 seconds with no GPU-skip message; seven Gumball interaction tests also passed. This isolates the observed contention for this run, not its underlying driver cause or desktop responsiveness.
