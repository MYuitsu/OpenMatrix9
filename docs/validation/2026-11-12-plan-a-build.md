A further integration test launches Cargo's actual `om9` executable with `--mcp` in a separate process. It creates a 4×5×6 box, saves and opens it, selects it, executes `ExtractWireframe`, and checks the 12 distinct output curves against the analytic box corners and edges. One Undo removes all 12 and Redo restores them. The full MCP stdio batch passed 7 tests. This covers the command interface and one box, not a physical menu click, arbitrary source geometry, or desktop rendering.

An egui integration fixture separately reopens the box, uses simulated viewport pointer events to select it, and invokes ExtractWireframe via either a simulated Curve icon click or typed CMD input. Both routes produce the 12 distinct analytic box edges; complete document snapshots match after Undo and Redo. The corresponding DupEdge icon/CMD fixture also passed, as did 45 wireframe tests (3 ignored) and six curve-menu tests. This runs egui frames without a physical desktop click or GPU presentation and is not a claim about other shapes or inputs.

An additional offscreen GPU fixture reopened the box, waited for a published Perspective wireframe image, and selected the box using a pointer event projected through the displayed camera. The menu handler then produced 12 analytically checked, distinct box edges, and one Undo/Redo restored the complete snapshots. An offscreen GPU texture remained available after the operation; this test does not inspect pixels to prove that all new curves were presented, nor does invoking the menu handler simulate clicking its icon. The test requires a GPU adapter and passed without a skip; the old-display DupEdge GPU fixture also passed. No physical desktop interaction was performed.

The GPU fixture was subsequently extended: after Undo/Redo it deletes the source box in the isolated test document, captures the image with the extracted curves, deletes those curves, and captures the empty-scene image. A 7×7 pixel neighborhood around the projected midpoint of each of the 12 edges changes between the two images. This demonstrates rendered output near those sampled midpoints, not every pixel along each curve or real desktop presentation. The test passed with a GPU adapter; no user's document was modified.
