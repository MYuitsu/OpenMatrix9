# Top11 Control Points: select and delete one NURBS grip — 2026-10-31

Status: PARTIAL_CHECKS_PASSED. The normalized Matrix reference requires selecting and deleting control points. OM9 previously provided drag only and Delete could remove the selected object.

The viewport can now select one control grip and highlight it; Delete is consumed while any grip mode is active so it cannot delete the object when no grip is selected. A selected grip is invalidated by document revision, mode changes and drag; deletion rechecks the current selected handles and publishes one geometry transaction. For a clamped nonperiodic NURBS with more than degree+1 poles, Rust deletes the chosen pole and weight plus an interior knot nearest its Greville station. This knot choice is an OM9 implementation choice; exact Matrix knot-selection semantics remain unverified. Undo/Redo restore the document. Lines, surfaces, polycurves, periodic and trimmed NURBS and minimum-pole curves are rejected without mutation; multiple-grip selection/deletion is not implemented.

Controller tests check pole, weight, knot, domain, reverse flag, stale handle, minimum count and Undo/Redo; unsupported line and surface are rejected and a core periodic fixture rejects deletion. A headless UI test uses projected-grip hit selection and sends the raw Delete key, checks that no-selected-grip Delete preserves the object, and exercises Undo/Redo. A separate existing raw Delete test confirms object deletion remains available outside grip mode. This is not a full simulated click/physical UI acceptance.

Two UI tests passed separately. General delete semantics, closed-curve preservation, multiple grips, surfaces, 3DM, physical viewport focus and M03-UI human acceptance remain open.
