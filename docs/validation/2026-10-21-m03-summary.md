# Object summary through SDK v1 — 2026-10-21

A plugin can count the document's objects by geometry kind. Owner: `OM9-L2-03-20`
(`OM9-L3-03-20-004`, Jewelry Object Count And Type Summary).

## Changed

| Layer | Change |
|---|---|
| Public SDK | `ObjectSummary { total, by_kind }` and `Host::object_summary`; one request and capability entry. |
| Host | Counts the open document, excludes objects deleted by this command and includes objects it already added, so a later step in the same command sees a consistent summary. |
| Example plugin | `SummaryDemo` returns the counts. |
| Tests | Host test for the base point/curve counts, a staged mesh add and a staged line delete; native DLL test for the 3-curve profile. |

## Semantics fixed by this slice

- Counts are staged-consistent: base objects plus this command's additions minus its
  deletions.
- Kinds are the geometry tags (`Point`, `Curve`, `Mesh`, `Brep`, `Surface`, `Cloud`,
  `Instance`, `Hatch`, `Light`); a kind with no object is absent rather than zero.
- Reading stages no mutation.
