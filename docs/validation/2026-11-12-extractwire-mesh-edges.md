# ExtractWireframe on a mesh source

The scene builder displays each triangle or quad face's perimeter, without its quad tessellation diagonal. ExtractWireframe now supports a single selected mesh root by enumerating its source face edges, sorting and deduplicating unordered vertex-index pairs, and making a line curve per resulting edge with the source entity placement. Distinct vertex indices remain distinct even if they occupy the same positions; a zero-length edge refuses the transaction. Source and scene/permission checks precede extraction. Temporary edge and output arrays are reserved through the coordinator before preparation; one transaction publishes the output.

A reopened fixture with a quad and a neighboring triangle checks six distinct expected edges, excludes the quad diagonal, preserves translation, saves and reopens the result, and verifies one Undo/Redo. Simulated managed memory pressure keeps the snapshot and existing Redo and succeeds after release. A separate zero-length edge fixture also preserves snapshot and Redo. The full wireframe integration suite passed 49 tests; four diagnostics were ignored. The six general curve-menu dispatch tests also passed, but do not exercise mesh extraction through a physical menu.

This tests one single-root mixed triangle/quad mesh and one degenerate fixture, not every mesh, affine transform, desktop interaction, native process peak, multi-root or mesh/B-rep mixed selection. Geometrically coincident edges with different vertex indices are intentionally not welded; no inference is made that mesh is a B-rep. This does not complete ExtractWireframe or Plan A.
