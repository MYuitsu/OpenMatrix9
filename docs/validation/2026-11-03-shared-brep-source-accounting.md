# Retained B-rep source accounting follow-up

Retained-owner inventory identifies the immutable B-rep source by allocation identity within the current document and across Undo/Redo and external captures. Equal source strings in independent allocations remain separate charges. The indexed inventory and allocation-free fallback agree in the exercised placement and alias cases; the index is included in admission accounting. The allocation-free per-document alias scan is quadratic in B-rep count and is not yet benchmarked on a large model; an admitted index may be needed. Other shared owner types still require independent accounting.

The separate initial `World::validate` inventory now also deduplicates these source allocations across simultaneously held documents. A two-document fixture with a shared source of 1 MiB and a 1.5 MiB cap failed with `Budget("bytes")` before the change and passed afterward, including when one document has multiple aliases. Independent equal sources still fail under that cap, and a corrupt display on one shared-source owner still fails validation. This does not establish global single-count admission for other owner types.

A placement/capture regression originally failed with 1,077,330 bytes before versus 2,155,615 bytes after; it passes with shared-source accounting. The subsequent same-document change tests two shared aliases under a limit below twice the source size, the last-owner charge, source sharing between an entity and a block definition, detached captures, independent allocations, Undo/Redo and the fallback inventory. The full core suite passed with two pre-existing ignored benchmarks before the added definition-specific test, which passed separately. Six OCCT B-rep selection/Undo cases, four STL background job cases, and all 11 offscreen GPU navigation/publication cases run sequentially passed in the prior follow-up. GPU results do not establish desktop responsiveness. These checks do not remove the existing 256 MiB ceiling, implement a global RAM budget, or separate display mesh from source.
