# Layer order through SDK v1 — 2026-10-21

A plugin can read the document's layer order (bottom to top). Owner: `OM9-L2-01-03`
(`OM9-L3-01-03-004`, Layer Domain Records).

## Changed

| Layer | Change |
|---|---|
| Public SDK | `Host::layer_order()` returning layer ids; one request and capability entry. |
| Host | Returns `document.layer_order` and appends a layer created by this command so a later step sees it. |
| Example plugin | `LayerOrderDemo` returns the order. |
| Tests | Host test for two base layers plus a created one appended; native DLL test that the created layer appears. |

## Semantics fixed by this slice

- Order is bottom to top as stored by the document; it is not re-sorted.
- A layer created in the same command is appended; the read never mutates the document.
- Reading stages no mutation.
