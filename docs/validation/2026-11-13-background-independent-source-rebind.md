# Background rebind for an independent canonical source

2026-11-13. When an OCCT remesh proof refers to a previous document allocation and the current canonical source is independently allocated, the caller captures a tracked source lease and lifecycle tokens. A worker compares the complete source and topology against the already native-attested lease, validates canonical integrity with admitted scratch, and constructs the native remesh candidate. Hashes used during proof lookup are candidate filters only. The worker does not change the public proof binding. Before preparing the scene, the receipt rechecks account, session/context, document owner, stamp, original proof binding and scene publication; only then does it bind the proof to the validated source. That binding does not attest the document display. A failure after binding but before scene publication can leave this technical source binding cached; it does not change the document or add an Undo step.
