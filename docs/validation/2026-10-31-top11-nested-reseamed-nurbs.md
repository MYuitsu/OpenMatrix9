# Top11 nested reseamed NURBS

The scene now displays a reseamed NURBS leaf in a direct or nested polycurve. Its traversal starts at the selected seam, follows each active knot span through the original domain boundary, and returns to the seam, including enclosing and leaf reversal. It splits the span containing an interior seam and uses the same traversal for admission and allocation. Before wrapping, native endpoint positions must coincide within a scale-aware floating-point bound; an open curve with seam metadata is rejected rather than given a false connector. Discontinuous internal knots remain rejected. This is an OM9 display admission check, not a proof of continuity for arbitrary imported curves.

Nested parameter trimming previously called the ordinary split operation on reseamed leaves, which is intentionally unsupported because a seam-spanning result cannot preserve that API's affine parameterization. Parameter trim now recurses into the existing seam-aware trim path. A seam-spanning piece may be represented by multiple exact segments with segment-uniform fractions; its geometry and tested cut endpoints are preserved, but an affine parameter mapping for the resulting composite is not claimed.

Scene fixtures exercise four seam positions, both leaf directions and both enclosing directions on a certified quadratic periodic curve, checking seam endpoints, sample continuity and exact point budget; a closed nonperiodic degree-one curve displays while an open one is refused. Application cases exercise Split and Trim with the periodic nested reseamed target, two cutters, both command routes and both enclosing directions, checking cut endpoints, `.om9` and Undo/Redo. A native 3DM fixture exports and imports the Split result and checks both endpoints of each piece; Trim 3DM and preservation of the original nested/seam representation remain unverified.
