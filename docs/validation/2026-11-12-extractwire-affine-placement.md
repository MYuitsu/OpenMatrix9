# ExtractWireframe: affine source placement

Previously ExtractWireframe refused selected B-reps with non-rigid placement. For a non-rigid root, it now retains the original B-rep placement on each extracted local source curve instead of baking that transform into the NURBS control points. Each root in a multiple selection retains its own placement. Previously supported rigid-placement output continues to use the existing baked representation. The generic geometry commit path accepts placed items while existing callers continue to use identity placement. DupEdge still has its prior rigid-placement restriction.

After saving and reopening the source, a box fixture tests nonuniform scale, shear, and reflection combined with scale, each at 0.5 and 0.01 mm display deflection through menu dispatcher or CMD. All 12 distinct source edges match their local analytic corners and transformed midpoints, retain their source placement, survive another save/reopen, and Undo/Redo restores the entity sets. A selected output edge is measured with Length after reopening against its world endpoint distance. A second two-root fixture combines a box and a cylindrical shell with scale and shear: it yields 12 box edges, two ellipses and one seam; sampled world points match the independent transformed circle equation, another save/reopen preserves geometry and placement, and Undo/Redo passes. A scaled sphere fixture exercises the single-output transaction and samples its transformed seam against the ellipsoid equation. Object-count and memory-pressure multi-root tests include a scaled source and preserve document and Redo on refusal; releasing memory permits retry.

`cargo test -p om9-app --test wireframe --test curve_menu --test dup_border --target-dir L:/om9-target -j 2 -- --test-threads=1`: wireframe 43 passed, 3 ignored; curve menu 6 passed; DupBorder 9 passed. `cargo test -p om9-app --lib solid_input_regressions --target-dir L:/om9-target -j 2`: 93 passed. `cargo check -p om9-app --no-default-features --target-dir L:/om9-target -j 2` passed with existing warnings. The user approved recording the tested placement scope in feature guidance.

These tests do not prove geometric equivalence for every source, all affine matrices, extreme coordinates, or imported topology, nor desktop picking/rendering or native peak. Preserving a placement means consumers must continue to honor entity placement; the selected Length fixture is one downstream check, not certification of every downstream command. Native B-rep parsing/conversion allocations remain outside the Rust reservation.

## Reopened extracted curve used for extrusion

A controller integration test now extracts the lower circular source edge of a cylindrical shell with nonuniform scale and shear, saves and reopens the extracted output, and uses that curve as input to `ExtrudeCrv`. At 0.5 mm display deflection the menu dispatcher extrudes +5 mm; at 0.01 mm CMD extrudes −5 mm. In both cases the resulting B-rep retains the source placement, is a single closed solid, has world volume 40π mm³ and world Z bounds matching the requested direction. Undo/Redo restores the before/after entity sets. The oracle uses the known transformed radius and determinant; this is an authored fixture, not a guarantee for all curves or construction planes.

The affected integration batch then passed: wireframe 44 passed and 3 ignored, curve menu 6 passed, DupBorder 9 passed. No production behavior changed in this follow-up, and no desktop, native peak, or arbitrary imported-source claim is made.
