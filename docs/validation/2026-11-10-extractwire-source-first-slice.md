# ExtractWireframe: source-edge slice (2026-11-10)

The product dispatcher accepts one selected root attested OCCT B-rep and a rigid placement. It uses the same verified topology/source extraction and admission path as DupEdge, requests each topology edge once, applies placement, and publishes the set in one transaction. Degenerate or otherwise unsupported edges refuse the entire command; there is no partial output. Multiple roots, unattested input, nested instances, non-rigid placement, individual surfaces and isocurves are not supported by this slice. Native seam behavior beyond the tested cylindrical shell is not fully characterized.

`cargo test -p om9-app --test wireframe --test curve_menu -j 2 --target-dir L:/om9-target` passed: 16 wireframe tests and 6 menu tests. A product Box produces 12 source curves with one Undo/Redo; a cylinder-like shell produces both analytic circles and all topology edges at two display profiles with placement, through CMD and menu; a Sphere's degenerate edge refuses with document and Redo unchanged. The two display outputs are compared and the circular geometry is independently sampled. `cargo check -p om9-app --no-default-features -j 2 --target-dir L:/om9-target` and public source audit passed. Native peak, performance, desktop and additional geometries remain unmeasured.

Sampled arcs match the analytic quarter-circle and compare equal across profiles; numerical parameter-domain equivalence is not yet independently established.
