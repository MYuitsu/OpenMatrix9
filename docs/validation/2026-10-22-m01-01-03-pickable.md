# Pickability rule through SDK v1 — 2026-10-22

A plugin can ask whether one object is pickable under the effective visibility/selectability
rules. Owner: `OM9-L2-01-03` (`OM9-L3-01-03-006`, Layer Selection Visibility Rules).

## Changed

| Layer | Change |
|---|---|
| Public SDK | `Host::is_object_pickable(id)` returning a boolean; one request and capability entry. |
| Host | Reuses `object_attributes`, so the answer is `effective_visible && effective_selectable` from the whole layer chain plus object attributes. |
| Example plugin | `PickableDemo {"id": …}` returns the boolean. |
| Tests | Host test: locked layer stays pickable (locked blocks editing, not picking), hidden object is not pickable, unselectable object is not pickable; native DLL test for the profile object. |

## Semantics fixed by this slice

- Pickable = effective visible **and** selectable; `locked` does not change it.
- The flags are the effective ones after the layer chain, not the stored object flags.
- Reading stages no mutation.
