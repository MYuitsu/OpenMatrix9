# Inline hover RAM admission, 2026-11-04

The viewport previously reserved a worker snapshot and picking scratch only above 128 scene objects. For 128 or fewer objects it called `Scene::pick` synchronously without a shared reservation, even though a single mesh can require a large transformed-vertex workspace. The inline path now reserves the existing nearest-pick scratch estimate in the Controller's shared CPU-cache account alongside current scene/auxiliary usage, using a current physical sample when available. It retains the reservation through picking and releases it afterward. On refusal the old hover is cleared and a bounded retry is scheduled, so pressure can clear without moving the pointer. When no physical sample is available, this inline path uses the existing managed-account fallback.

Two controlled tests cover a 4,096-vertex single mesh (the shared lease includes at least the transformed-vertex estimate and is released) and a one-point UI fixture (a competing shared reservation causes refusal, then stationary hover succeeds after release). The former verifies estimated admission, not actual mesh picking or measured allocator peak. The latter simulates managed pressure, not OS-wide exhaustion. Eleven hover-filtered app tests passed before the additional mesh-only test; the two inline tests passed afterward. Twenty-five serial GPU/egui Gumball tests passed without adapter skips after the change. Default features, E: debug target, `-j 2`, OCCT runtime; initial hover build 27.73 s/tests 9.70 s, added-test build 26.98 s/tests 0.45 s, GPU tests 51.06 s.

The scratch estimate explicitly excludes allocator overhead, implementation-dependent sorting, evaluation and query allocations. Lazy picking indexes remain with the published scene after the temporary lease drops, and published-scene lifetime is not yet fully registered for shared-account peers. This is not a process-wide hard RAM bound, proof for all picking paths, a release benchmark or a physical desktop interaction test. The new admission and physical sampling costs on real navigation have not been measured.
