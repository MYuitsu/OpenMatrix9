# Top 11 Split/Trim: placed cutters (2026-10-30)

Standalone Rust OM9 on Windows, base commit `89ef2676b597ebc5ab38fa5c6acf0ad47a2f261b` with working-tree changes. Previously the controller rejected target and cutter with unequal placements, even when their world geometry intersected. A line/line regression first failed with that rejection. Trim also compared a world-space pick to local-space pieces, choosing the wrong interval for a translated target.

The controller maps a curve, NURBS surface, or (with OCCT) BRep cutter into the target frame before intersection; the target and its committed pieces keep their placement. Trim measures the pick against world-space copies of the pieces, but commits the original local pieces. Source cutter is preserved. A shifted surface test exposed a separate solver defect: a candidate was refined only if a coarse sample already lay inside tolerance. The solver now refines sampled local minima before checking the actual separation. This remains a numerical solver, not a guarantee of finding every intersection.

Checks with `CARGO_TARGET_DIR=L:\om9-target` and `-j 2`: core Top 11 plus curve/surface suites 27 passed; app Top 11, options and OCCT BRep suites 55 passed; app Top 11 and options without default features 40 passed. The added cases check actual world endpoints for translated line and surface cutters and a translated BRep, plus Undo/Redo where exercised; one non-intersecting surface case stays empty. `tools/public_source_audit.py` reported zero errors. The first BRep test run failed because the test incorrectly expected selection restoration after Redo; the corrected test verifies document geometry instead. Manual viewport clicks and M03-UI sign-off are not established.

Limitations at this batch: cutter intersection used fixed `1e-6` target-frame tolerance; a later [world-tolerance follow-up](2026-10-30-top11-cutter-world-tolerance.md) changes this and tests scaled fixtures. Numerical curve/curve and curve/surface solvers can miss pathological intersections, including between sampling minima; non-rigid BRep transformations, singular placements, closed curves, multiple-target Trim, surface/BRep targets, macOS, actual GPU/OS interaction and broader Top 11 commands remain open. Endpoint/tangency/overlap and high-complexity cases require independent oracles.
