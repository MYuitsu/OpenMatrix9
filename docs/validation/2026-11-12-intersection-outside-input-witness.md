# Checked Intersection: result outside an input

An exploratory check rotated a radius-3 mm sphere about its center and intersected it with the previously examined baked-affine box. At a 45° X rotation and center x=0.001 mm, OCCT returned a checked solid with volume 113.097335529 mm³, approximately the whole sphere, instead of the analytic 56.576942097 mm³ spherical cap. A reopened controller fixture reproduced publication of this wrong body. The sphere input's measured volume and bounds were independently checked; this does not certify every point of the imported B-rep.

The user approved rejecting a checked solid Intersection when a sampled point of the result is classified inside that result and outside every solid in either input.
