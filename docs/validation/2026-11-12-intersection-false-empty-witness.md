# Checked Intersection: false-empty witness

The user approved rejecting a checked solid Intersection result reported empty when a point can be numerically classified inside both inputs. The existing OCCT Difference witness routine now also handles that case. It samples 27 points inside the first input's bounding box, classifies against at most eight solids per input, and only rejects when OCCT reports `TopAbs_IN` for at least one solid from each input. It runs only for checked solid Boolean Intersection with a null/no-face result. A missing witness is inconclusive and leaves the prior Empty behavior unchanged; it does not prove emptiness or repair the Boolean geometry. The native adapter is necessary for OCCT shape/classifier APIs; Rust continues to own controller, document and transaction. `editing_bridge.cpp` SHA-256 at this validation: `5bff366d253b8bd28a37d2c4e2f244a89175189213d2d1f64b252a0581580286`; a [later guard](2026-11-12-intersection-outside-input-witness.md) changed the file further.

In the 24 near-centered baked-affine sphere–box combinations (six offsets, two operand orders, two display profiles), 12 negative-offset combinations previously returned false Empty and now reject with the new witness error; the other 12 still reject through existing OCCT validity checks. No result was repaired or accepted in this fixture. The regression asserts that a future accepted body must match analytic spherical-cap volume, be one closed solid and have no naked edges. Two genuinely disjoint controls—separated boxes and spheres with overlapping bounding boxes—remain Empty in both operand orders and profiles. On reopened inputs, grouped Intersection and Boolean Two preview refuse the witnessed result while preserving the document and an existing Redo; successful Boolean paths retain their existing Undo/Redo regressions.

The test suite uses the pinned OCCT 8.0.1 SDK. Kernel `l2_01_10` passed 89, with one unrelated nonuniform-affine Union fixture ignored; app Solid controller regressions passed 94. The Solid integration suite passed, and Solid workflows passed 114 with one native-UI fixture ignored. Classification uses floating point and the existing 1e-7 local classifier tolerance; it is not a mathematical proof, a document-wide tolerance policy, or exhaustive coverage. The 8-solid/27-point bound limits classifier calls, not OCCT topology-map allocation or native peak memory. Imported shapes, tiny overlaps, extreme placements, physical desktop, and all callers beyond the checked solid path remain unverified.
