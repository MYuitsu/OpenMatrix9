# Ring candidate publication with a transient lease

Follow-up: [the coordinated Apply transfer](2026-11-13-ring-preview-apply-transfer.md) supersedes the Apply refusal described in this earlier record; direct insertion of transient leased geometry remains refused.

2026-11-13. The controller can explicitly publish a current worker candidate into the Builder session. Its external reservation is attached to the B-Rep before publication and follows B-Rep clones, transferred source owners and display pins. Raw display extraction and topology rebinding are refused while this owner is attached. The owner drops after the B-Rep display and source allocations; normal equality and serialization do not include it. The controller admits additional space before constructing preview handles and summary and checks the actual capacities afterwards.

The attached lease must not enter Document/Undo: reservation destruction can otherwise try to reacquire the coordinator's account lock while that lock is already held. Consequently the explicit staged preview currently refuses Apply; generic geometry and document validation also reject a B-Rep carrying this transient owner. This restriction does not change the ordinary synchronous Builder path. A checked transfer into document accounting is still required before the background preview can be used as a production UI path.
