# Block definitions through SDK v1 — 2026-10-21

A plugin can read the document's block definitions (label, member count, revision). Owner:
`OM9-L2-01-03` (`OM9-L3-01-03-008`, Block Definition And Instance Graph).

## Changed

| Layer | Change |
|---|---|
| Public SDK | `BlockDefinitionInfo { id, label, members, revision }` and `Host::block_definitions`; one request and capability entry. |
| Host | Maps `document.definitions` to the DTO; read-only, no instance insertion or definition edit. |
| Example plugin | `BlocksDemo` returns the list. |
| Tests | Host test for a definition with one member; native DLL test that the command round-trips on a document without blocks. |

## Semantics fixed by this slice

- Member count is the record's member count; the label and revision are preserved.
- Only reading is exposed, so a plugin cannot fabricate an instance or mutate a definition.
- Reading stages no mutation.
