# Top11 Mirror: circles under in-plane similarity transforms

Previously a circle under uniform scaling, or scaling that was uniform only within its plane, was converted into a rational quadratic NURBS. Its geometric locus remained circular but its fractional angular parameterization changed. The curve-baking code now examines the transformed in-plane basis, retaining a circle and scaling its radius when its axes remain orthogonal and equally scaled. The check uses a relative allowance of eight `f64` epsilons for numerical roundoff. General anisotropic or sheared in-plane transforms continue to use the existing rational ellipse conversion; its fractional parameterization is not generally the original linear angle parameterization.

An application regression first failed because the reflected result was NURBS. It now passes for uniform 3D scale and a reflected nonuniform 3D transform that is uniform in the circle plane, using CMD and toolbar paths, Copy Yes/No, five point fractions, original parameter/angle domains and Undo/Redo. A separate regression checks that a `1e-10` difference between in-plane scales produces a NURBS ellipse and preserves its tested extremum, rather than being misclassified as a circle by the old rigid-transform tolerance.

A real-native 3DM test mirrors a uniformly scaled custom-domain arc, exports and imports it, and compares the imported circle type, its domain and angle domain and five fractional points. Windows x64 used `CARGO_TARGET_DIR=L:\om9-target`, `-j 2` and native adapter SHA-256 `d2e2ae9501a23b0568c28359f8d25058f249c85636598b8a76ba2c07bc98b1ab`. This is an interoperability test, not an openNURBS measurement batch.

The full Top11 integration suites passed: 106 app tests and 31 core tests, plus 106 app tests with default features disabled. Existing no-default unused-code/import warnings remain. Wider transforms, ellipse parameter fidelity, other UV/3DM cases, real desktop input and GPU presentation remain open. The subsequently identified line and circle reversal domain defect is addressed in [reversal evidence](2026-10-31-top11-reversed-domains.md).
