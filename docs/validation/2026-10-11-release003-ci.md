# v0.0.3 public build transition

Approved scope: compact English-first/Vietnamese-second release notes, two latest
Windows ZIPs, a shared SHA256 file, and an actual GitHub Actions source build with
provenance. The published 0.0.2 tag and historical downloads remain unchanged.

Packaging test first failed because the existing builder emitted 0.0.2. Installer
test first failed because Read-OM9Manifest rejected 0.0.3. The release.json-driven
builder and strictly numeric compatible-host manifest now pass those regressions;
installer passed 27 checks and updater/shortcuts passed 17. Public source audit
reported no errors before CI dependency installation.

The repository-wide Python tooling discovery was also run: 99 tests, 37 failures,
33 errors. Exact names/reasons are preserved in
[tooling results](2026-10-11-release003-tooling.json). It includes historical
reference exporter/icon tests, absent local Rhino/oracle/SDK evidence fixtures,
and audit fixtures that called the private Matrix.rui exporter. The audit test
fixture was corrected to use a self-contained authored SVG (assertions unchanged);
its 11 tests now pass. Other historical failures remain outside the release gate
and are not represented as passing. The release gate runs package/audit tests,
installer/updater, complete Rust suite, analytic native BRep oracle and actual
stock FreeCAD GUI/plugin/worker checks. This does not recertify all Matrix/Rhino
workflows or unfinished commands.

GitHub publication is permitted only after a matching version tag on reviewed
main passes build, tests, packaging and provenance. Binary hashes and build URL
are generated for that run in release-validation.json inside both ZIPs. No old
OM9 native binary is uploaded as a GitHub-built artifact.
