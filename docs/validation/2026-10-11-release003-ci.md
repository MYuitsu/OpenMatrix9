# v0.0.3 public build transition

Approved scope: compact English-first/Vietnamese-second release notes, two latest
Windows ZIPs, a shared SHA256 file, and an actual GitHub Actions source build with
provenance. The published 0.0.2 tag and historical downloads remain unchanged.

Packaging test first failed because the existing builder emitted 0.0.2. Installer
test first failed because Read-OM9Manifest rejected 0.0.3. The release.json-driven
builder and strictly numeric compatible-host manifest now pass those regressions;
installer passed 27 checks and updater/shortcuts passed 17. Public source audit
reported no errors before CI dependency installation.

The repository-wide Python tooling discovery was also run: 99 tests, 37 failures,
33 errors. Exact names/reasons are preserved in
[tooling results](2026-10-11-release003-tooling.json). It includes historical
reference exporter/icon tests, absent local Rhino/oracle/SDK evidence fixtures,
and audit fixtures that called the private Matrix.rui exporter. The audit test
fixture was corrected to use a self-contained authored SVG (assertions unchanged);
its 11 tests now pass. The [complete post-fixture rerun](2026-10-11-release003-tooling-after-fixture.json)
has 99 tests, 37 failures and five errors. Other historical failures remain outside the release gate
and are not represented as passing. The release gate runs package/audit tests,
installer/updater, complete Rust suite, analytic native BRep oracle and actual
stock FreeCAD GUI/plugin/worker checks. This does not recertify all Matrix/Rhino
workflows or unfinished commands.

GitHub publication is permitted only after a matching version tag on reviewed
main passes build, tests, packaging and provenance. Binary hashes and build URL
are generated for that run in release-validation.json inside both ZIPs. No old
OM9 native binary is uploaded as a GitHub-built artifact.

The first hosted native integration run
[38093391285](https://github.com/MYuitsu/OpenMatrix9/actions/runs/38093391285)
compiled the plugin and passed Rust, installer/updater and the eight analytic
BRep fixtures. Its GUI timed out: the runner exposed OpenGL 1.1 and reported
access violations. The isolated CI profile now selects FreeCAD's bundled software
OpenGL renderer before QApplication startup and creates the custom home directory
(FreeCAD ignores nonexistent homes). The launcher/user rendering settings are
unchanged. Four profile regression checks pass. The same two CI macros on the
local official 1.1.4 host pass 14 native checks and five worker checks with the
exact selected module; the software context reports OpenGL 3.0. Hosted rerun
remains mandatory before publication.

Hosted rerun [38094955170](https://github.com/MYuitsu/OpenMatrix9/actions/runs/38094955170)
passes compilation, all release-gate tests, packaging and both ZIP attestations:
262 Rust tests, eight analytic BRep fixtures, 14 native and five worker checks,
27 installer and 17 updater checks. Its exact native module and binary hashes
are recorded in that run's summary. Qt's software OpenGL context reports 3.0,
but stderr still contains Coin context warnings and handled access violations.
Thus this run establishes native ABI/CAD/worker/install behavior, not clean
viewport rendering. [FreeCAD issue 7303](https://github.com/FreeCAD/FreeCAD/issues/7303)
describes a likely Qt/Coin software-renderer mismatch in an older version; it
does not prove the cause of the current messages. The same macros pass locally
on desktop GPU without access violations; CI-built/downloaded ZIPs must also
pass that desktop native check before publication is claimed complete.

The plugin ZIP downloaded from run 38094955170 also passes those exact macros
on the local official FreeCAD 1.1.4 desktop host: 14 native and five worker
checks, the module path points into the extracted CI ZIP, and stderr contains
no access violation, failed context or invalid GL context. This supports the
native desktop integration scope; it does not turn the hosted software-renderer
messages into a clean viewport certification. The final tag ZIP is checked again
after publication with provenance, manifest/native hashes and launcher tests.

Final tag run [38096298917](https://github.com/MYuitsu/OpenMatrix9/actions/runs/38096298917)
passes build, all release-gate tests, ZIP provenance and publication for source
`2330e20af4aa5b050eaa928f7728766c02a3924d`. The published downloads contain
541 identical plugin files; both native hashes match this tag run. GitHub CLI
cryptographic verification binds both ZIPs to the repository, workflow, exact
tag/commit and a GitHub-hosted runner. The downloaded final plugin passes 14
native and five worker checks on the desktop GPU without access violations;
the downloaded launcher passes 21 real installation/GUI/icon/Start Menu/update
checks. [Published verification receipt](2026-10-11-release003-published.json)
records the asset digests and results. The hosted rendering limitation remains;
the release tag/assets were not changed to add this post-publication receipt.
