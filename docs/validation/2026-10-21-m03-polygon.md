# Polygon creation through SDK v1 — 2026-10-21

This completes the creation kinds of `OM9-L3-02-04-002` for the plugin boundary: a plugin can
now close a point list into one polygon, in addition to circles, arcs, ellipses, rectangles
and NURBS curves. It reuses `curve_build::polyline` and the shared output path.

## Changed

| Layer | Change |
|---|---|
| Public SDK | `Host::add_polygon(label, points)`; one request and capability entry. |
| Host | Accepts three or more distinct points; if the caller already repeated the first point it is not appended twice; the polygon closes once and uses `curve_build::polyline`. A degenerate edge, duplicate consecutive point or fewer than three distinct points is a `curve` refusal. |
| Example plugin | `CurveShapeDemo` also creates a rectangle-sized polygon and reads its info/semantics. |
| Tests | Host test for an open list and a caller-closed list (both 4 segments, closed, planar), one Undo, and the two-point / duplicate-point refusals; native DLL test asserts the polygon and the 3→6 object / Undo / Redo sequence. |

## Semantics fixed by this slice

- A polygon is a closed polycurve: the first point is appended when the caller did not repeat
  it, so the caller may pass either an open or an already-closed list; the closing point is
  never appended twice.
- Fewer than three distinct points, repeated consecutive points or a zero-length edge are a
  `curve` refusal; the polygon is never silently reduced to a line.
- The polygon publishes as one object in the command's single transaction and one Undo
  removes it.
- The result reports `polycurve` with `segments = point count`, and `curve_semantics` reports
  it closed and planar when the points are coplanar.
