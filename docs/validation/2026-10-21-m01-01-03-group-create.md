# Group creation through SDK v1 — 2026-10-21

A plugin can create one group from existing member ids. Owner: `OM9-L2-01-03`
(`OM9-L3-01-03-007`, Group Membership Model).

## Changed

| Layer | Change |
|---|---|
| Public SDK | `Host::create_group(name, members)` returning the group id; one request and capability entry. |
| Host | Validates a bounded non-empty name and existing non-deleted members, stages `Mutation::GroupCreate` with the base revision, and appends the staged group to `groups()` reads. |
| Example plugin | `GroupCreateDemo {"members": [...]}` creates "SDK set". |
| Tests | Host test for create + commit + Undo and the empty-name/unknown-member refusals; native DLL test with two profile members. |

## Semantics fixed by this slice

- Members must be existing, non-deleted objects; an unknown id is `missing` and a bad name
  is `group`.
- Creation is one `Mutation::GroupCreate` at the base revision, so it participates in the
  command transaction and one Undo removes it.
- A later `groups()` read in the same command includes the staged group.
- The group record keeps the member order the caller supplied.
