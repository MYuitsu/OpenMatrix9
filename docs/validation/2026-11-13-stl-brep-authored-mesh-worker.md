# Mixed B-rep and authored-mesh STL worker

2026-11-13. The STL worker previously retained the complete immutable document for any selection mixing a B-rep with an authored mesh. For selections containing at least one OCCT/native B-rep and no NURBS surface, capture now retains tracked B-rep sources, occurrence metadata and a pending, admitted allowance for authored-mesh copies. It initially retains the document to protect those mesh inputs. The export worker copies the meshes with cancellation checks, transfers their actual capacities to the reservation and releases the document before constructing the STL. Mesh vertices, faces, normals, colors and UVs remain source data; they are not discarded as viewport display. A synchronous export still uses the retained document path.

The mixed fixture uses an OCCT sphere and a reflected, translated authored triangle. After worker-side capture, the source-only and retained-document paths produce identical soup, warnings and binary encoding; after a document edit and controller teardown the detached capture does not keep the old document or B-rep display alive. The production `StlExportJob` also wrote an STL for this mixed selection and returned the expected triangle count. A canceled capture releases its reservation. These assertions do not independently establish all source geometry or native peak memory.

With OCCT runtime on PATH, `CARGO_TARGET_DIR=L:\om9-target`, `-j 2`: `cargo test -p om9-app -j 2 --lib session::stl::cancellation_tests` passed 55; `cargo check -p om9-app -j 2 --no-default-features` passed with 21 warnings. Public source audit: 15,997 files, 594 bindings, 593 SVGs, no errors. Artifact pruning removed 0 and retained 169 older cited runs.

Limitations at this checkpoint: the document remains live until mesh copying finishes; each occurrence originally received its own mesh copy. The later [shared-mesh follow-up](2026-11-13-stl-shared-mesh-source.md) removes that duplication for repeated occurrences. A selection containing a NURBS surface still uses the retained-document path. The change does not establish native transient peaks, GPU/desktop behavior, source-only Document/Undo, general eviction, cold restore or v5. Continue the canonical ownership migration rather than treating this consumer transition as C1 completion.
