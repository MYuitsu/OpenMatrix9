# Curve length measurement through SDK v1 — 2026-10-21

A plugin can now measure a curve's sampled length in object-local millimetres. Owner:
`OM9-L2-03-20` (`OM9-L3-03-20-001`, Distance And Length Measurement).

## Changed

| Layer | Change |
|---|---|
| Public SDK | `Host::measure_curve_length(id)` returning `MeasuredDistance`; one request and capability entry. |
| Host | Requires curve geometry, samples with `surface_kernel::sample_curve(curve, 33, limits)` and sums consecutive point distances; a non-curve is `unsupported`. |
| Example plugin | `LengthDemo {"id": …}` returns the length. |
| Tests | Host test for a 10 mm line, a radius-5 circle within 1% of 2πr, and the point-object refusal; native DLL test for the 10 mm line. |

## Semantics fixed by this slice

- The value is a **sampled** length: 33 samples, summed chords. It is an approximation for
  highly curved curves, not exact arc length.
- `unsupported` for non-curve geometry; sampling failures are `measure`.
- Reading stages no mutation; the placement is not applied.
