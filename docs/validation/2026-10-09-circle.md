## Corrections verified during implementation

The initial native Circle run loaded the older module beside the SDK executable,
despite the `-P` search path argument, and correctly failed on disabled Circle.
The smoke macros now assert the selected module path; all regressions above
ran against the newly built module. They do not rely on the earlier failed run.

A small 3Point red test reproduced misuse of a length tolerance on a
square-length cross product. Normalization fixed it; Rust and native tiny-circle
checks passed. Independent review found that F4 did not refresh the frame before
the first point after a viewport switch. Fixed that branch; the native
Looking Down → Through Finger → F4 case now produces the X/Z circle plane.

The captured `circle-runtime.png` was inspected. It retains existing OpenGL
capture artifacts in the workspace; it does not certify rendering quality.
Analytic geometry and transient Coin coordinates were checked independently.

## Remaining acceptance scope

Tangent/Point/FromFirstPoint, AroundCurve, FitPoints, Deformable/Degree/PointCount,
3Point Radius after two points, Area point sizing and the original right-click
2Points shortcut remain unsupported. Active-layer mapping, associative History,
document-wide tolerance policy and exhaustive Matrix compatibility are not
accepted. The exact engineering contract and sample in spec_v1 stay unchanged;
implementation notes and checkmarks only describe the verified slice.
