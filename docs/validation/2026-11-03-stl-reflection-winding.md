# STL placement reflection winding

P3a partial implementation of the viewport/export separation plan. STL collection now flips each source object's triangle winding after a negative-determinant placement. The correction is applied after the mesh, B-rep, native B-rep or surface path has generated its own triangle range, before the current weld and writer. Positive-determinant placement retains its existing order. No canonical geometry is edited.

Windows, default features including OCCT, `CARGO_TARGET_DIR=L:/om9-target`, Cargo `-j 2`: `cargo test -p om9-app -j 2 --test stl_export` passed 11 tests. The new integration test exports and independently reads an authored open mesh after a negative-X placement and checks that the encoded triangle retains its expected +Z orientation. Existing tests cover box, sphere, open surface, native B-rep and destination handling, but do not exercise a reflected B-rep, reflected surface, nested cavity, non-manifold condition or multiple coincident sources. Those remain open. This is not evidence for a general STL tolerance or manufacturing-accuracy guarantee.

`tools/public_source_audit.py` passed with zero errors. This batch did not build or measure a release executable and did not interact with the live desktop session. The global weld, premature f32 conversion, topology parity test, export tolerance, 3DM verification, runtime memory budget, GPU budget, checkpoint and other acceptance gates remain outstanding. Next: add reflected solid/cavity tests and implement source-separated welding and robust topology/error checks as specified by `implementation/design/M01/viewport-export-separation-20261102/PLAN.md`.
