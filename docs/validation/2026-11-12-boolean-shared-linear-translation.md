# Boolean shared affine linear map with distinct translations

The shared-placement Boolean paths previously required every placement matrix to be identical. They now also accept matching linear coefficients when a local translation can be computed and transformed back to exactly the supplied world translation. The first object's placement becomes the common frame; other local sources are moved by a rigid translation before Boolean, and each output retains the frame. If linear coefficients differ or translation reconstruction fails, the path falls back to the existing world-placement restriction. Exact coefficient comparisons and the reconstructed origin check do not prove pointwise floating-point equivalence for every coordinate, nor do they bound OCCT tolerance under extreme scales.

The controller regression creates two overlapping boxes with the same nonuniform scale, shear, or reflection but different translations, saves and reopens them, and exercises Union, Boolean Two (Union mode), Difference, Intersection and Split at two display profiles through menu dispatch and CMD. For each of the 30 combinations it checks output frame, analytic local volume, expected piece count, and Undo/Redo. In the shear case the local offset has both X and Y components, so the inverse must account for shear. Separate pre-existing tests check refusal and Redo preservation when linear maps differ. The tests do not establish curved/imported topology, arbitrary Boolean Two modes, extreme or ill-conditioned maps, geometric error over large coordinate ranges, native peak, or interactive desktop. The original baked-affine sphere/box failure remains open.
