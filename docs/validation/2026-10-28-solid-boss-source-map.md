# Solid Boss source and implementation gap — 2026-10-28

The normalized local Matrix 8 text associated with the Truncated Cone milestone includes the adjacent Boss section. It describes selecting one or more closed planar curves, confirming, then selecting a surface or polysurface boundary. The curves extrude normal to their plane toward that boundary; the boundary is trimmed and joined to the extrusions. This is a distinct operation from an arbitrary fixed-height extrusion or a Boolean union with a closed solid.

The recovered Matrix90 VB6 menu registration (`modMillC_Defaults.bas`, `Proc_198_35_1A2F840`) associates `SolidBoss` with `! _Boss` in the `Solid` group, consistent with the normalized milestone menu binding. This registration does not reveal Rhino's underlying geometry algorithm, selection filters, defaults, treatment of multiple intersections or object deletion. No decompiled source is reproduced here.

Current standalone inventory has a SolidBoss icon bound to `OM9-SOLID-021`, but the Solid command owner does not handle that feature and `Controller::availability` rejects it. A targeted Rust test verifies that Boss, Rib and Slab stay present in the Solid palette catalog and unavailable; it does not exercise actual sidebar clicks or desktop display. Rib and Slab are included only in that availability check, not as Boss semantic evidence.

Implementation requires an exact planar-profile-to-boundary construction that trims and joins the chosen boundary, a staged selection session sharing menu/CMD state, and atomic document/history publication. Existing straight extrusion alone is insufficient. The next step is to inspect selected OCCT operations and existing split/sew support for an intersection with a finite BRep boundary, including non-intersection, multiple hits, orientation, and ownership. Then implement a bounded kernel fixture before enabling any menu or command. UI and original-behavior evidence remain open.
