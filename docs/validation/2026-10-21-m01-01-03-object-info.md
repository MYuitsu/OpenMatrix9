# Single object record read through SDK v1 — 2026-10-21

A plugin can read one object's `ObjectInfo` without paging a query. Owner: `OM9-L2-01-03`
(`OM9-L3-01-03-002`).

## Changed

| Layer | Change |
|---|---|
| Public SDK | `Host::object_info(id)` returning the same `ObjectInfo` a query page contains; one request and capability entry. |
| Host | Reuses the existing `object_info(&Entity)` mapping, so query and single read cannot diverge. |
| Example plugin | `InfoDemo {"id": …}` returns the record. |
| Tests | Host test for id/label/kind/identity placement; native DLL test for the profile curve record. |

## Semantics fixed by this slice

- The record is byte-for-byte the query page's `ObjectInfo` (same helper), including flags
  and revisions.
- Reading stages no mutation.
