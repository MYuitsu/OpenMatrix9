# Clear current layer through SDK v1 — 2026-10-21

A plugin can clear the document's current-layer pointer. Owner: `OM9-L2-01-03`
(`OM9-L3-01-03-004`, Layer Domain Records).

## Changed

| Layer | Change |
|---|---|
| Public SDK | `Host::clear_current_layer()`; one request and capability entry. |
| Host | Stages `SetCurrent { layer: None }` only when a current layer is set; clearing an already-clear document stages no mutation. |
| Example plugin | `ClearLayerDemo` clears it. |
| Tests | Host test for clear + commit + Undo, and the no-op case; native DLL test that `LayerDemo` then `ClearLayerDemo` leaves `current_layer = None`. |

## Semantics fixed by this slice

- Layer records are untouched; only the pointer becomes `None`, so new objects use the
  document default.
- A no-op clear stages no transaction, matching the owner's "no empty mutation" rule.
- Undo restores the previous current layer.
- Clearing is one layer-plan mutation, so it composes with other layer plans in the same
  command like the rest of the layer service.
