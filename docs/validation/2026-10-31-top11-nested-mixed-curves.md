# Top11 Split and Trim: nested mixed curves

The scene previously admitted nested polycurves only when every leaf was a line, so a valid connected nested arc or NURBS could not be selected for Top11. The Rust scene now walks nested line, arc and continuous nonperiodic unseamed NURBS leaves in order, applying reversal at every level. Direct and nested segments use the same sample routine. The existing knot-span-aware NURBS sampling and arc chord bounds remain in effect. Admission checks continuity before drawing, charges the same point count as the display buffer, and rejects unsupported or discontinuous leaves rather than inventing connectors.

The scene fixture combines a line, arc and quadratic NURBS under nested reversal, tests both outer directions and both NURBS orientations, verifies a point on the curved span and exact budget boundaries. The existing discontinuous NURBS rejection is also exercised at nested depth. The application fixture tests both Split and Trim, each via command and toolbar dispatch, on one nested arc and one nested quadratic NURBS. It checks the cut endpoints, `.om9` roundtrip and Undo/Redo. A real native 3DM test exports and reimports the two resulting Split documents and checks both cut endpoints; it does not establish preservation of the original nested structure or external Rhino behavior.

Windows x64, `CARGO_TARGET_DIR=L:\om9-target-top11-nested`, `-j 2`: complete scene suite, 130 app Top11, 84 app BRep, 10 options and three command-snapshot tests passed. The no-default-feature app Top11 suite passed 130 tests with existing warnings. The explicitly invoked native Split roundtrip passed both geometry fixtures using adapter SHA-256 `bddca46577747333f9377b379351a077b710158f47ce6e279d7b6e21e6439615`. This is 3DM interchange, not an openNURBS measurement batch. The original build directory remains in use by a separate open desktop test session.

Nested full circles, periodic or seamed NURBS remain outside this display admission; unsupported or discontinuous geometry is reported, not drawn as a connected strip. Other nested structures, extreme scales, general intersection precision, 3DM Trim, real pointer/GPU and human M03-UI acceptance remain unverified. This evidence does not establish completion of Top11.
