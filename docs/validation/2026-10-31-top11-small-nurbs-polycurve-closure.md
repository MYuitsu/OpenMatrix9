# Top11 closure classification for small NURBS and polycurves

The fixed `1e-9` endpoint threshold classified open NURBS and polycurves of total length `1e-10` as closed, so Trim removed the wrong cyclic interval. For non-line, non-circular curves with nonidentical endpoints, Top11 now caps that absolute threshold by `1e-9` times a sampled geometric extent. Exactly coincident endpoints remain closed; a reseamed NURBS is classified using its unseamed base. This is a conservative sampled rule, not a proof of closure for arbitrary curves. The line/quadratic intersection path uses the same classification so it does not turn an open NURBS endpoint at fraction `1` into a seam at fraction `0`.

The core fixtures verify short open degree-one NURBS and polycurves, their reversed forms, true closed small NURBS and a small closed square, as well as near-gap cases at three scales. They check Trim endpoints and separately verify that a line meeting the end of a small open multi-span quadratic NURBS returns fraction `1`. CMD and toolbar Split/Trim tests use a `1e-13` mm document tolerance with `1e-10`-length open NURBS and polycurves, checking counts, remaining length, `.om9` roundtrip and Undo/Redo.

A real 3DM test found a separate limitation: native export rejects the complete document because its `2e-10`-length line cutters fail native geometry validity. Exporting a document with one such line alone reproduces the refusal. Exporting and importing only the three resulting NURBS pieces succeeds and retains their endpoints. This was checked with admitted native adapter SHA-256 `bddca46577747333f9377b379351a077b710158f47ce6e279d7b6e21e6439615`; it is a 3DM interoperability check, not an openNURBS measurement batch. The full-document export remains unresolved and was not represented as a success.

Windows x64, `CARGO_TARGET_DIR=L:\om9-target`, `-j 2`: 204 core library, 42 core Top11, 29 core curve/surface, 128 app Top11 and 84 app Top11 BRep tests passed; 128 no-default app Top11 tests passed with existing warnings. The reversed-case assertion and native diagnostic were rerun individually after the full suite.

The sampled closure bound may conservatively reject unusual near-closed curves whose extent falls between samples. Extreme underflow, general overlapping curves, full 3DM export with very short native lines and physical desktop acceptance remain open. These tests do not establish completion of Top11.
