## Real-fixture corrections and limits

The real ring initially exposed an open shell after export: the exporter incorrectly imposed `1e-6` tolerance on geometry with a larger source/kernel tolerance. Export now retains source tolerance as `OM9Tolerance` and uses the maximum required kernel tolerance in the archive. Import uses original 3D edge curves plus their trims, rather than repeatedly approximating edges from pcurves. Export reads and converts its staged output before replacing the destination.

Optimal analytic bounding boxes are compared without triangulation or tolerance padding; ordinary display bounding boxes can vary with NURBS representation despite identical geometry. Independent extrusion numerical checks use the explicitly recorded archive tolerance.

Actual Rhino 5 application opening was not tested. Archive version 5 is represented as 50 by modern openNURBS on readback. Blocks, annotations, plugin objects, materials/textures and parametric history are not supported. FreeCAD triangle facets preserve original quad topology in metadata for unchanged meshes. Layer groups/metadata do not complete all original Layer UI commands. The full original 130-feature Core goal remains incomplete.
