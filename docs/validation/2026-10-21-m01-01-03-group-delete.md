# Group deletion through SDK v1 — 2026-10-21

A plugin can delete one group record; member objects stay. Owner: `OM9-L2-01-03`
(`OM9-L3-01-03-007`).

## Changed

| Layer | Change |
|---|---|
| Public SDK | `Host::delete_group(id)`; one request and capability entry. |
| Host | Validates the group id (base or staged), records it in a deleted set, filters it from `groups()`, and stages `Mutation::GroupDelete` at the base revision. |
| Example plugin | `GroupDeleteDemo {"id": …}` deletes and returns the remaining groups. |
| Tests | Host test for delete + commit (members stay) + Undo and the unknown-id refusal; native DLL test for create→delete→Undo. |

## Semantics fixed by this slice

- Deleting a group removes only the record; member entities are untouched.
- The deletion is one `Mutation::GroupDelete` at the base revision, so one Undo restores it.
- `groups()` no longer lists a group deleted by the same command.
- An unknown id is `missing`; a malformed id is `id`.
