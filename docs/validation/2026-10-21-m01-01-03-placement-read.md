# Object placement read through SDK v1 — 2026-10-21

A plugin can read one object's local placement matrix without querying the whole page.
Owner: `OM9-L2-01-03` (`OM9-L3-01-03-002`).

## Changed

| Layer | Change |
|---|---|
| Public SDK | `Host::object_placement(id)` returning a row-major 4x4; one request and capability entry. |
| Host | Returns the staged placement when the command set one, otherwise the base entity placement. |
| Example plugin | `PlacementReadDemo {"id": …}` returns the matrix. |
| Tests | Host test for identity then a staged 7 mm translation; native DLL test for the profile object's identity matrix. |

## Semantics fixed by this slice

- The matrix is object-local; a parent/instance composition is not applied here.
- The read reflects the command's own staged placement, so a set-then-read sequence is
  consistent inside one command.
- Reading stages no mutation.
