# STL per-export linear profile

Follow-up: the linear profile is now exposed in the menu/CMD dialog; see [dialog evidence](2026-11-03-stl-quality-dialog.md). The statements below describe the earlier profile-only delivery.

P3a partial implementation. `Controller::export_stl_selected_with_profile` accepts a positive finite linear tolerance in output millimetres and applies it consistently to the existing B-rep deflection request, sampled surface, weld radius and STL quantization budget. The existing `export_stl_selected` remains a wrapper that takes the document's effective absolute tolerance. `StlExportReceipt` and the `om9_export_stl` MCP response report `requested_tolerance_mm`, explicitly a request, not a certified achieved deviation. MCP accepts an optional `linear_tolerance_mm` and advertises it in its schema; requests omitting it use the same document default.

Windows default features including OCCT, `CARGO_TARGET_DIR=L:/om9-target`, Cargo `-j 2`: `cargo test -p om9-app -j 2 --test stl_export` passed 18 tests, including a sphere exported at 0.05 mm and 0.001 mm from the same B-rep; the finer request produced more triangles, the document was unchanged and invalid finite/nonfinite profiles preserved existing destination bytes. `cargo test -p om9-app -j 2 --test mcp_stdio stl_export_profile_is_reported_and_invalid_profile_preserves_file` passed 1 test. Despite the test file name, it invokes the in-process JSON-RPC server directly; it verifies the published schema, the requested tolerance and topology metadata, and invalid-input destination preservation, not an operating-system stdio subprocess.

The native save-dialog/UI does not yet expose the profile; menu and typed command continue using the default wrapper. Angular tolerance remains the existing fixed 0.3 rad, surface meshing remains sampled, and the default requested tolerance is not a total geometric-error guarantee. Immutable background capture, cancellation, resource reservations, topology-aware generated seams, 3DM, GPU budgets, checkpoints and matched release/desktop performance gates remain open. The currently running OM9 session was not modified.
