# Mesh area through SDK v1 — 2026-10-21

A plugin can measure a polygon mesh's surface area. Owner: `OM9-L2-03-20`
(`OM9-L3-03-20-001`, measurement extension for area).

## Changed

| Layer | Change |
|---|---|
| Public SDK | `MeasuredArea { square_millimeters }` and `Host::measure_mesh_area(id)`; one request and capability entry. |
| Host | Fan-triangulates each face around its first vertex and sums triangle areas in object-local space; a non-mesh is `unsupported`. |
| Example plugin | `AreaDemo {"id": …}` returns the area. |
| Tests | Host test for a 10×10 quad (100 mm²) and the line refusal; native DLL test for the 100 mm² quad mesh. |

## Semantics fixed by this slice

- Area is the sum of planar triangle areas from a fan triangulation of each face; a
  non-planar quad is measured as its fan triangles, not as a curved surface.
- Coordinates are object-local; the placement is not applied.
- A non-mesh object is `unsupported`, never a guessed zero.
- Reading stages no mutation.
