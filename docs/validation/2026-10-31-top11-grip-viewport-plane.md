# Top11 grip drag: clicked viewport construction plane

When a grip drag started in an inactive viewport, the pointer ray came from that viewport but the construction plane came from the previously active viewport. For example, a Through Finger ray could be parallel to the Looking Down plane and no drag started. The viewport now uses its own CPlane for the gesture and becomes active after the initial ray intersects that plane. If the ray cannot intersect it, the UI reports a construction-plane error and keeps the selected grips and document unchanged. Previously the error was silent and selected grips were cleared.

Both failures were reproduced by egui pointer tests before the respective fixes. A 16-case fixture covers Control Points and Edit Points on Lines and bilinear NURBS surfaces in Through Finger, Side View, Perspective and Looking Down; each drag begins with a different active viewport. The Looking Down case uses a plane tilted 45 degrees. It checks the preview, no mutation before release, world-space endpoint or pole, active viewport, `.om9` save/open and Undo/Redo. A separate edge-on CPlane case verifies a visible error, unchanged selection, no transaction and unchanged active view. An existing normal-scale and sub-nanometer grip-drag pair was rerun.

Windows x64, `CARGO_TARGET_DIR=L:\om9-target-top11-nested`, `-j 2`: the two viewport-plane tests passed with default and no-default features; after adding `.om9` checks they passed again with default features. The two existing grip-drag tests and 133 Top11 controller tests passed. The no-default build emitted existing unrelated warnings. Source SHA-256: `ui/top11.rs` `76555c30c8b754fc9f60a8b354803e62f65c952663de885d8d27f9bdcfd39c68`; `ui/chrome.rs` `62868c07f153e3fc0445c2fe1327a932bbdb7d6a601671cdce02226b0ff613f`.

This is simulated egui input, not physical mouse, GPU presentation or human M03-UI acceptance. Other CPlane orientations, viewport changes during an active drag and general surface geometries remain unverified. No native adapter or openNURBS measurement batch was involved.
