# Import provenance through SDK v1 — 2026-10-22

A plugin can read the retained import source proof for one object. Owner: `OM9-L2-01-03`
(`OM9-L3-01-03-013`, Import Source Provenance Metadata).

## Changed

| Layer | Change |
|---|---|
| Public SDK | `ObjectProvenance` and `Host::object_provenance(id)`; one request and capability entry. |
| Host | Reuses `Document::provenance`, so the plugin sees the same complete-chain rule as the core; enums map to the fixed strings below. |
| Example plugin | `ProvenanceDemo {"id": …}` returns the proof or `null`. |
| Tests | Host test imports a real `.3dm` bundle and checks name/hash/version/mode/kind/index/family/disposition plus the `null` case for a native object; native DLL test for the `null` case. |

## Semantics fixed by this slice

- A proof is reported only when the retained chain is complete (namespace bound to the
  object, source hash agreement, declared archive version); anything less is `null`, never a
  guessed native import.
- Strings are contract values: mode `preserve`/`geometry` (or null); kind `geometry`,
  `layer`, `definition`, `material`, `light`, `history`, `group`, `line_type`, `dim_style`,
  `hatch_pattern`, `texture_mapping`, `image`, `render_content`, `embedded_file`,
  `other:<native_type>`; disposition `unchanged`/`edited`/`deleted`/`retained_only`.
- `source_sha256` is lowercase hex of the retained source bytes.
- Reading stages no mutation.
