# Circle radius measurement through SDK v1 — 2026-10-21

A plugin can now read a native circle/arc radius. Owner: `OM9-L2-03-20`
(`OM9-L3-03-20-002`, Angle And Radius Measurement).

## Changed

| Layer | Change |
|---|---|
| Public SDK | `Host::measure_curve_radius(id)` returning `MeasuredDistance`; one request and capability entry. |
| Host | Matches `Curve::Circle { radius, .. }` (including an arc angle domain); any other curve kind is `unsupported`, never a guessed radius. |
| Example plugin | `RadiusDemo {"id": …}` returns the radius. |
| Tests | Host test for an arc radius 5 and the line refusal; native DLL test for the 5 mm profile circle. |

## Semantics fixed by this slice

- Only native circle geometry has a radius; a line, NURBS or polycurve is `unsupported`.
- The value is object-local millimetres and matches the record's radius exactly (no sampling).
- Reading stages no mutation.
