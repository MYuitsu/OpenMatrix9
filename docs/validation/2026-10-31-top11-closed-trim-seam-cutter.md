# Top11 Trim: a cutting point at the closed-curve seam

With a diameter and a radial cutter, a circle had three distinct cuts, one at its parameter seam. Picking the first quarter previously removed both intervals adjacent to the seam, leaving only a quarter instead of three quarters. Trim now distinguishes a seam that is an actual cut from a seam that merely separates one continuous cyclic interval. It removes only the selected interval and still joins the retained portions across the seam when the selected interval lies elsewhere. The direct curve-cutter API and the single/multiple-target cutter collection retain closed-curve endpoint hits; open curves still treat their endpoints as endpoints. A single seam hit on a closed target remains non-destructive.

Core fixtures check seam fractions `0` and `1`, picks on either side and a pick in a different interval. A polycurve cutting tool verifies the direct cutter path. An additional regression showed a `1e-10`-length line was treated as closed and its nonzero remainder discarded by a fixed `1e-9` cutoff; Trim now treats lines as open and retains nonzero pieces, while the command's document-tolerance rules remain in effect. Split and Split Point selection likewise do not classify a line as closed solely because its endpoints are close.

The application test covers CMD and toolbar, selecting both cutters with the target before starting or selecting them afterward, picks on either side of the seam, exact boundaries and arc length, `.om9` roundtrip and Undo/Redo. The retained three-quarter arc and its boundaries also survived real 3DM export/import using admitted native adapter SHA-256 `bddca46577747333f9377b379351a077b710158f47ce6e279d7b6e21e6439615`. This interoperability test is not an openNURBS measurement batch.

Windows x64, `CARGO_TARGET_DIR=L:\om9-target`, `-j 2`: 204 core library, 38 core Top11, 28 core curve/surface, 126 app Top11 and 83 app Top11 BRep tests passed; 126 no-default app Top11 tests passed with existing warnings. The additional retained-across-seam assertion was rerun individually after the full suite. One native 3DM roundtrip passed.

General curve-overlap behavior, closure classification for non-line geometry near tolerance, extreme underflow, more closed NURBS and BRep cutter cases, and physical desktop acceptance remain open. These tests do not establish completion of Top11.
