# Checked Intersection: missing-interior witness

The prior centered, 45°-rotated sphere–box fixture produced a nonempty intersection with 56.439498818 mm³ instead of the analytic 56.548667765 mm³. A standalone OCCT diagnostic read that result: standard volume integration gave 56.439498758 mm³ and Gauss–Kronrod calculations at three requested tolerances converged near 56.439498818 mm³. Of 6,466 grid points safely inside the analytic hemisphere, OCCT classified 6,462 inside the result, three outside and one inconclusive. One missing point, `[0.2, 1.8, -2.0]`, is analytically inside the radius-3 sphere and the box. The sampling and classifier are numerical, not a global proof of shape equivalence. Probe source: `implementation/design/M01/viewport-export-separation-20261102/intersection-volume-probe.cpp`; its inputs can be generated by the opt-in ignored kernel diagnostic using `OM9_INTERSECTION_DIAGNOSTIC_SOURCE` and `OM9_INTERSECTION_DIAGNOSTIC_DIR` pointing to new paths.

The user approved trying a bounded guard. For a nonempty checked solid Intersection, it samples 24 points in the overlap of the input bounding boxes. If OCCT classifies a sampled point inside at least one solid of each input and outside every result solid, the operation is refused. Maps of inputs/results are limited to eight solids each; `ON` and `UNKNOWN` never prove a witness. The check does not prove correctness when no witness is found. It reuses native OCCT APIs because no shapes cross the FFI; Rust still owns the document and transaction. OCCT topology maps, classifier allocations and peak native memory are not bounded by the sample count.

Initially the 24-point check missed this fixture: the in-memory first operand after Boolean classified the sampled point outside, whereas a fresh read of the same immutable source classified it inside. The checked Intersection witness paths now re-read both canonical input sources after OCCT's operation before classifying; a failed read refuses rather than commits. This avoids relying on the possibly altered working operands, at the cost of extra native reads and memory. `editing_bridge.cpp` SHA-256: `a1d33e5cd9cb13fdaa27898629948cebd3c75b96de19db36491284aadbc3566f`.

The previously accepted centered fixture is now refused for both input orders and two profiles; after save/open the controller refuses it while retaining document and Redo. The separate 30-combination rotational diagnostic, explicitly run, passed: valid volumes are checked analytically while recognized invalid results are refused. The outside-input and false-empty fixtures and two disjoint controls remain covered. These observations do not fix the OCCT operation or demonstrate that every invalid result is detected.

For a limited timing observation, the previously built test executable (with the earlier Intersection guards but without re-reading inputs or this 24-point guard) and the new test executable each ran a 16-combination valid sphere–box Intersection test twice, alternately, in debug mode. Whole-process wall times were before 7.319/7.388 s and after 8.076/7.769 s (about 5–10% longer in these paired runs). Process start, fixture construction and measurement are included; this is not a per-operation benchmark, native peak measurement or representative performance guarantee.

With the pinned OCCT 8.0.1 SDK, the kernel Boolean suite passed 91 tests with two ignored (the opt-in parameterization diagnostic and an unrelated affine Union issue); the diagnostic was also explicitly run and passed. The Solid controller group passed 95 and Solid workflows passed 114 with one native-UI fixture ignored. The user approved recording the checked behavior in feature guidance. The independent probe's opt-in fixture generation was rechecked with fresh temporary paths.

## OCCT configuration probe

An independent, test-only OCCT 8.0.1 probe tried 16 `BRepAlgoAPI_Common` configurations on fresh copies of the centered rotated sphere and box: non-destructive mode on/off, OBB on/off, and fuzzy values 0, 1e-7, 1e-6 and 1e-5. All 16 were accepted by `BRepAlgoAPI_Check` and produced the same 56.439498818 mm³ result, short of the analytic 56.548667765 mm³. The known missing point was outside each result. In this fixture, the sphere operand's classification at that point changed from inside to outside after the operation when non-destructive mode was off, and remained inside when it was on. This directly supports re-reading the original source for the witnesses; non-destructive mode alone did not repair this case. The probe does not test every OCCT setting or demonstrate non-mutation for arbitrary shapes. Source: `implementation/design/M01/viewport-export-separation-20261102/intersection-occt-options-probe.cpp`; generated source fixtures were cleaned after the run. No production setting changed.

To distinguish an already-wrong transformed sphere from the Boolean result, the independent probe subsequently classified all 6,466 sampled points from the analytic hemisphere against both freshly read inputs as well as the unchecked Common output. Every sampled point was classified inside both inputs; three were outside the result and one was inconclusive. This supports, for these interior samples and this fixture, the conclusion that the missing region arises in the Boolean result. It does not prove the entire input sphere is geometrically exact, locate the internal OCCT defect, or explain errors at unsampled points. The diagnostic used opt-in generated source fixtures, which were deleted after the run; no product change followed.

## Plane representation and local-frame experiment

**Later update:** the narrowly certified temporary-box path was subsequently implemented and tested. The earlier refusal described here is historical for shapes that now qualify; see [certified-box evidence](2026-11-12-intersection-certified-box.md) for its exact scope and remaining refusals.

The transformed box in this fixture has six `GeomAbs_BSplineSurface` faces; `GeomLib_IsPlanarSurface` recognizes all six as planar at 1e-9 mm. An independently constructed analytic-plane box spanning the same coordinates agrees with the transformed box at 125 sampled interior/exterior point classifications. This is evidence for the fixture, not a proof of globally equal trimmed topology. Intersecting the rotated sphere with that analytic box returned a valid result of 56.548667765 mm³ and classified the earlier missing witness inside. In contrast, the transformed box yielded the short volume across all 16 configurations above. Surface representation is therefore a plausible contributor; this comparison does not isolate OCCT's internal root cause or justify replacing arbitrary spline faces by planes.

A separate opt-in kernel diagnostic transformed the sphere into the unscaled box's local frame and ran checked Intersection with the original analytic box: three sphere offsets, both operand orders and both display profiles gave 12 closed, single-solid results with volumes within 1e-5 mm³ of the corresponding analytic local cap. This experiment assumes access to the original box and its placement; a reopened, already baked B-rep does not establish that provenance. World-space error, source/trim equivalence, downstream use, native peak and desktop were not verified, and no automatic reconstruction or production frame selection was added. Kernel test `intersection_rotated_sphere_box_local_frame_diagnostic` remains opt-in.

Further source inspection found that all six transformed box faces in this fixture are non-rational, nonperiodic degree-(1,1) B-splines with 2×2 control poles, and all 12 edges are non-rational, nonperiodic degree-1 B-splines with two poles. These properties make a narrowly certified analytic conversion conceivable, but they do not alone prove that an arbitrary solid is a box, that all trims and face/edge relationships match, or that replacing it preserves tolerances and topology. A product implementation would need an exact, bounded certificate and negative cases before using a reconstructed shape solely as a temporary Boolean operand. No such certificate or production conversion was implemented in this step.
