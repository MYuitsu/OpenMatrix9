# STL export of selected block occurrences

STL export previously accepted only selected root mesh, B-rep, NativeBrep and NURBS surface entities. Selected instances were skipped or refused, even when their definitions contained supported geometry. Selection capture now expands nested definition occurrences from the captured immutable document, composes placements in hierarchy order, and exports each occurrence separately. The final placement determines reflection winding and export meshing tolerance; distinct occurrences do not share weld ownership. Occurrences have checked depth, cycle, count and cancellation handling. Unsupported leaf types remain listed as skipped. Members hidden by their own or an ancestor's visibility/layer state are included and produce a receipt warning rather than disappearing silently.

The red/green nested-mesh fixture selects two occurrences of a two-level definition, includes a reflection, independently decodes the binary STL and checks both placements, winding and no Undo. A second fixture exports two actual OCCT sphere occurrences with a separate STL profile and checks both positions, triangle counts and indexed closedness. A third fixture checks that a hidden block member is included and reported. Unit tests cover instance cycles, depth, cancellation and inherited visibility. On E: default features with `-j 2`, 14 STL cancellation/admission unit tests and all 45 STL integration tests passed. Public-source audit reported no errors.

These fixtures do not certify global source-to-STL error, self-intersection, cavity correctness, every nested native/NURBS type, visibility semantics against Matrix/Rhino, or desktop behavior. Native tessellation remains independently subject to the plan's unfinished RAM-budget work. The enabled runtime behavior changes from refusing instance-only selections to exporting supported nested members; the visibility policy above is not yet a reusable skill rule.

## Incremental occurrence traversal and capture

The initial implementation built a list of every leaf occurrence before processing it. It now invokes a bounded-depth visitor for each leaf and retains only the definition traversal stack, avoiding that full additional occurrence list. It still builds the output soup, topology maps and native data, and traverses during readiness and again for export. No full aggregate reservation, large-model peak memory result or timing improvement is established. An additional integration fixture captures an instance, moves the live instance, and checks that the exported mesh retains the earlier captured placement while the live document retains its edit. Existing cycle, depth, cancellation, visibility and nested/reflected instance checks are rerun.

On E: default features with `-j 2`, all 14 STL cancellation/admission unit tests and all 46 STL integration tests passed after this change. Public-source audit reported no errors.
