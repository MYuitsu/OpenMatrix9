# Group records through SDK v1 — 2026-10-21

A plugin can read the document's group records (id, name, members, revision). Owner:
`OM9-L2-01-03` (`OM9-L3-01-03-007`, Group Membership Model).

## Changed

| Layer | Change |
|---|---|
| Public SDK | `GroupInfo { id, name, members, revision }` and `Host::groups`; one request and capability entry. |
| Host | Maps `document.groups` to `GroupInfo`, preserving member order and revision; read-only. |
| Example plugin | `GroupsDemo` returns the list. |
| Tests | Host test for a group with one member; native DLL test that the command round-trips on a document without groups. |

## Semantics fixed by this slice

- Member ids are returned in document order, as strings; the group revision is the record's.
- Only reading is exposed: creating, editing or dissolving a group is not part of this
  version, so the SDK never fabricates membership mutations.
- Reading stages no mutation.
