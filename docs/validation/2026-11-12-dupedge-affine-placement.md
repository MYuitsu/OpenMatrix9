# DupEdge: non-rigid source placement

DupEdge previously refused scale and shear. For reopened B-reps, the source-pick path now transforms the picked point back to source coordinates, matches its displayed segment against the same native source map, and retains the source placement on the resulting curve. The document/source segment tolerance is conservatively divided by an upper bound on the placement's linear stretch; the pick must round-trip to world space within the chosen world tolerance. For non-rigid placements the resolved source point is also checked against the viewport cursor and depth. A required local verification tolerance below 1e-12 mm is refused. These checks supplement, not replace, existing edge-ambiguity and sampled display/source verification; the three segment interior samples are not a continuous error bound. In-session attested picks use their existing verified map and retain non-rigid placement as well.

After saving and reopening Box sources, controller tests select two displayed edges for nonuniform scale, shear, and reflection combined with scale at 0.5 and 0.01 mm display profiles. World endpoints match the independently transformed selected endpoints; one Undo/Redo restores the entity sets. A cylinder scale/shear fixture selects a displayed circle near a segment endpoint and checks sampled output points against its world ellipse equation at both profiles. In the first implementation, a coarse midpoint whose resolved source point was too far from the viewport pick was refused; the subsequent recovery change is documented below. An extreme-scale fixture refuses because the required local tolerance is below the supported threshold and preserves Redo. A deliberately false cylinder display chord is rejected for both identity and non-rigid placement.

A headless egui viewport test opens a scaled/sheared Box, clicks two visible edges and checks both world endpoint pairs and Undo/Redo. A separate temporary source-view worker fixture verifies a selected affine edge is published with its placement and Undo/Redo; the source-view regression batch also covers cancellation and admission/refusal. The attested path has a non-rigid one-edge fixture. These checks do not establish all matrices, degenerate placements, occlusion cases, topology reordering combinations, imported models or actual desktop clicks.

Validation: `cargo test -p om9-app --lib source_pick_tests --target-dir L:/om9-target -j 2` passed 11; `cargo test -p om9-app --lib dupedge_source_view_tests --target-dir L:/om9-target -j 2` passed 16. The `wireframe`, `curve_menu`, `dup_border`, and `solid_difference_ui` integration batch with `--test-threads=1` passed 217 tests with 6 ignored. `cargo check -p om9-app --no-default-features --target-dir L:/om9-target -j 2` passed with existing warnings. Native OCCT allocation peak and desktop behavior remain unmeasured. The user approved recording this tested scope in feature guidance.

## Coarse affine view recovery

For an affine pick whose source-resolved point fails the viewport position or depth check, the command now requests the existing private source-view worker and asks for a fresh selection rather than ending the attempt. A regenerated source view uses the source deflection capped at 0.01 mm (an already finer profile is preserved); this applies to other source-view recovery requests as well. The cap is an engineering choice, not a guarantee that every transformed or zoomed curve will fall within the cursor tolerance. The temporary-view check does not recursively trigger another rebuild; unresolved picks remain refused. Worker or memory failure leaves the document and Redo intact.

In the reopened scale/shear cylinder fixture at a 0.5 mm original profile, a coarse midpoint now schedules recovery. A busy-worker case preserves the pending command, document and Redo; after release, canceling the pending worker also preserves document and Redo, and a new attempt can build the 0.01 mm view. Selecting its regenerated segment produces the source curve with correct placement, analytic sampled geometry and Undo/Redo. A separate headless egui fixture exercises the full click, rebuild, select-again and commit path with the same oracle and Undo/Redo. These fixtures do not establish recovery under every resource condition or guarantee it makes every coarse pick usable.

After the change, source-pick tests passed 11; source-view worker tests passed 16; the filtered viewport DupEdge suite passed 25 with 3 ignored; wireframe passed 44 with 3 ignored, curve menu 6 and DupBorder 9 passed. The no-default-features check and public source audit passed. Desktop and native peak remain unmeasured. The user approved recording the fixture-scoped recovery behavior.
