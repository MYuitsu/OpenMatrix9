- **Implemented / bounded evidence (I/B):** source path exists and a matching test or recorded acceptance covers a bounded behavior. It does not close a larger numbered fixture.
- **Implemented / unverified (I/U):** source exists, but this audit did not find complete acceptance of the requirement. Next action is verification or a precise extension, not an automatic rewrite.
- **Partial / implementation gap (P/G):** source demonstrates only a subset, or another enabled path bypasses it. Must implement then verify.
- **Missing (G):** no implementation found in the inspected Rust/native routes; identified search scope is not a claim about all FreeCAD addons.
- **Outside P0 (X):** only where chapter 06 explicitly assigns P1/P2, or UI content is clearly display/layout/advanced organization. A related P0 permission/identity invariant remains in scope.
- A feature may remain safely unavailable while its runtime is unsupported. That is evidence for truthful capability gating, not evidence that the missing runtime contract has been fulfilled. Do not silently remove open RCORE-04 scripting contracts from an all-P0 completion claim.
