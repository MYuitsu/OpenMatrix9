# PictureFrame implementation plan

Scope: OM9-VIEW-001 from the local spec, within the full130-spec core objective. Preserve `PictureFrame` public name. No PDF reread or broad Curve refactor.

1. Implement and test Rust placement geometry: source pixel aspect, first corner, second reference point or positive CMD width, current construction-plane basis, Shift orthogonal snapping and Vertical plane. Finite bounded coordinates and nonzero dimensions are required. Invalid input must not create output. Document OM9 defaults separately from recovered option cues.
2. Add a focused native controller, using original command mapping and shared menu/CMD session. Choose a valid raster image through QFileDialog, then prompt for a corner and width/direction; Esc, document/workbench changes and denied task permissions cancel without creating geometry. Mouse rays intersect the current native C-plane. CMD accepts coordinates and scalar width. Preview must remain transient until commit.
3. Commit one `Image::ImagePlane` inside a document transaction. Native plane vertices are centered on Placement, so convert the selected corner to the rectangle center. Assign ImageFile before XSize/YSize because the native view provider initializes size on image load. Native Placement and XSize/YSize provide moving/scaling. Embedded image persistence uses PropertyFileIncluded. SelfIllumination maps native No shading; alpha handling uses raster components. Explicit defaults/options must be documented; do not label unnormalized cues as recovered semantics.
4. Verify menu/CMD and Qt mouse placement using a generated asymmetric fixture image, aspect and orientation/corner correctness, cancel/invalid input, model selection/history invariance, Undo/Redo, native texture display, moving/scaling and FCStd reload after removing the source image. Test Vertical and Shift. Check supported option behavior; retain gaps explicitly rather than marking missing cues complete.
5. Build Rust/C++/ABI in an isolated output, preserve open preview processes, and update requirements/progress from actual native results.

Files: `rust/src/core_picture_frame.rs` for pure geometry and session semantics; native `Gui/CorePictureFrame.h/.cpp` for interaction/commit; existing command, workbench and CMD routing for registration; `tests/core_picture_frame_smoke.FCMacro` for native evidence. A new native object/view-provider class is unnecessary because the host provides Image::ImagePlane.
