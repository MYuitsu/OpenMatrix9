## Design

Implement Center, Diameter, Corner, Vertical, FromFoci with optional MarkFoci, AroundCurve and Deformable. Exact output is a closed analytic ellipse wire; equal axes are a circle. Deformable output is a periodic B-spline with requested degree/pole count and measured sampled approximation deviation. AroundCurve uses a bounded native edge and tangent-normal plane. Ellipse plus foci share one transaction and current layer. No History feature is implied by the source; History requests explain the unsupported scope.

Host choices: default Center, Deformable=false, Degree=3, PointCount=8, MarkFoci=false; no source defaults claimed. Center/Diameter axes project into the latched construction plane; Vertical uses its normal as second axis. Corner is aligned with CPlane X/Y. FromFoci plane follows the three input points; coincident foci are rejected with a recoverable message. Minimum radius 1e-7 mm, finite analytic extent within +/-1e9 mm. Numeric axis entry uses millimetres; Diameter's first number is the full diameter. Invalid inputs do not advance; Undo removes the last point; preview never writes document objects.
