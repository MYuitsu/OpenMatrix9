# Rhino 5 3DM Exchange Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans for inline implementation. Steps use checkbox syntax for tracking.

**Goal:** Add CAD-preserving Rhino 5 .3dm import/export to OpenMatrix9, build it and prove it in FreeCAD.

**Architecture:** Rust owns command identity, permissions, supported-type policy and success state. Native openNURBS reads/writes archives; C++ converts OpenNURBS/OpenCASCADE geometry and applies FreeCAD transactions. A standalone converter test target exercises geometry without a GUI; host tests exercise the same handler exposed through native bindings.

**Tech Stack:** Rust edition 2024, C++23, MSVC x64, Qt 6.11.2, OpenCASCADE 8.0.1, openNURBS 8.x pinned to `eb92af3ba1806b0a34a99aba0d3bda83e3d46083`, existing FreeCAD SDK.

**Spec:** `docs/superpowers/specs/2026-10-06-rhino5-3dm-design.md` (user approved 2026-10-06).

## Global Constraints

- Archive output version 5; explicit millimeter units and tolerance metadata.
- Import into the active editable document; export selected whole objects in that document, using world placement.
- Exact CAD geometry stays CAD geometry; never silently tessellate NURBS/BRep.
- Import commits one Undo transaction; cancel/conversion failure leaves geometry unchanged.
- Export stages a sibling temporary file and replaces the destination only after success.
- Preserve imported source behavior; mark new rules as OpenMatrix9 decisions.
- Do not change native Save semantics, builder/history records, installed skills or unrelated user files.
- Unsupported blocks/annotations/plugin objects fail with a clear preflight report; no silent object loss.
- Use the existing H: checkout/build dependencies; isolate converter build artifacts under ignored `build` directories.

## Review Focus

1. Rational/periodic geometry, seams and inner trim loops must retain valid topology: Task 2/3 numerical and validity fixtures.
2. Unitless/custom-unit files must not be guessed: Task 1 policy and Task 4 explicit scale/cancel tests.
3. UTF-8 names, duplicate layer names and hidden/locked objects must retain metadata: Task 4 collision/save-reopen tests.
4. A selected Body/Link/container must export world geometry once: Task 4 placement and duplicate-selection tests.
5. Conversion or write failure must preserve existing document/file data: Task 3 malformed preflight and Task 4 rollback/atomic-write tests.

Conversion functions throw a typed `ExchangeError` with geometry context on unsupported/invalid data.

- [ ] Implement curve/surface conversion with explicit knot multiplicity and domain handling, preserving rational weights and orientation. Convert supported analytic surfaces to exact NURBS for exchange.
- [ ] Implement mesh conversion retaining vertices and face winding, rejecting invalid/degenerate indices. Preserve mesh object type.
- [ ] Run converter tests, including independently constructed OpenNURBS input and independently constructed OpenCASCADE output. Repeated round trip alone is not evidence of correctness.
