**Spec:** `OpenMatrix9_Codex_Spec_v1/specs/00-rhino-core/01-object-model-kernel.md`, especially enabled consumers, owned input/output, immutable source identity and one atomic publication.

## Global Constraints

- Reuse current geometry solvers and input semantics; Rust first for independent values/validation.
- Preserve 16MiB/1million nodes/depth64; native owner pointers never enter Rust results.
- Shape, metadata, units, layer, links/History and cache changes require one checked GUI transaction; reject stale/live-lock changes before commit.
- Preserve all source geometry, analytic/NURBS basis, attributes, frame and ordered selections. A sampled outline does not certify CAD geometry or conversion/maps.
- Build standalone OpenMatrix9Gui only with the existing cache/SDK. No root build or runtime clone.
